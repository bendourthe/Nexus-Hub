### Skills Framework Benefits

- ❌ Navigate complex directories
- ❌ Copy-paste large files
- ❌ Full template loads into context (token-heavy)
- ❌ Manual selection

- ✅ Natural language: "Use the cleanup-python skill"

- ✅ Discoverable in Claude Code
- ✅ Composable workflows

### No Breaking Changes
- All existing templates remain unchanged
- Skills are **additive**, not replacements
- Users can choose templates **OR** skills
- Skills reference templates as sources
