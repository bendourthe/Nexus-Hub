# Phase 1: Context Analysis & Initial Assessment

## 📋 Overview

This phase focuses on gathering comprehensive context about the codebase, understanding its purpose, architecture, and identifying areas requiring detailed review.

## 🎯 Objectives

- Understand project purpose, scope, and architecture
- Identify critical components and dependencies
- Map out code structure and organization
- Establish review priorities and focus areas
- Document initial observations and concerns

## 📂 Available Templates

### Python
- **[Python Context Analysis](python_context_analysis.md)** - Complete template for analyzing Python codebases including project assessment, architecture mapping, dependency analysis, and review planning

## ⏱️ Time Investment

**1-2 hours** for comprehensive context gathering and initial assessment

## ✅ Success Criteria

- [ ] Project purpose and scope documented
- [ ] Architecture overview created
- [ ] Critical components identified
- [ ] Dependencies mapped
- [ ] Review priorities established
- [ ] Initial concerns documented
