# Trivia Quiz

A tiny browser trivia quiz. Pick an answer for each question, then see your score.

## Run it

Open `index.html` in any browser. No build step, nothing to install.

## Code

- `index.html` is the page.
- `styles.css` is the styling.
- `logic.js` holds the pure scoring and state helpers (no DOM).
- `app.js` wires the logic to the page.
- `questions.js` is the deck.

## Status

Works end to end. A couple of rough edges in the scoring and the restart button. No tests yet.
