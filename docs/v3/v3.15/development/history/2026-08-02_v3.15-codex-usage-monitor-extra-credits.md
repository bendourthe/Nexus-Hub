## Goal

Show monthly Extra Credits usage as the second progress bar after Weekly in the Codex Usage Monitor hover tooltip and dashboard.

## Implementation

- Added a normalized `CreditUsageInfo` model with used credits, monthly limit, utilization percentage, and reset metadata.
- Mapped detailed credit usage defensively across workspace/monthly/extra-credit wrappers and snake_case/camelCase amount aliases, preserving the existing balance-only summary fallback.
- Refreshed monthly reset countdowns from cached data and included an expired monthly reset in the automatic refresh check.
- Rendered the Extra Credits bar, amount line, and reset time in both UI surfaces without changing rate-limit warning thresholds or compact status-bar text.
- Expanded behavioral coverage for dashboard lifecycle and messages, usage persistence and reset timing, settings persistence, and workbench color synchronization.
- Added a reproducible `test:coverage` command with enforced 80% line/statement and 75% branch/function thresholds.
- Bumped the independently versioned extension from 0.2.6 to 0.2.7 and updated its README.
