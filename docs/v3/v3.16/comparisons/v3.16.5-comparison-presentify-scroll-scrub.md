## Step 1.5 Source-Security Scan: PROCEED-WITH-CAUTION

The scan ran on a shallow clone (`%TEMP%/scroll-world-compare`) BEFORE any content was ingested as instructions. Tree is eleven files (~120 KB), no binaries, no package manifests.

| Check | Finding |
|---|---|
| Prompt injection / agent-directed overrides | None. No "ignore previous instructions", zero-width smuggling, HTML-comment payloads, or base64 instruction blobs. |
| Malicious / destructive code | None. `knockout.py` is a local PIL flood-fill; `scrub-engine.js` is vanilla DOM/CSS with no eval, cookies, or WebSockets. |

## What the source is

[scroll-world](https://github.com/oso95/scroll-world) is a single agent skill that builds an immersive, **scroll-scrubbed "fly through the world"** landing page for any brand or industry. As the visitor scrolls, a pre-rendered camera flies from outside each scene into its interior, then on to the next scene with no cuts - one continuous connected flight (Apple product-page / Emons-logistics style).

What's in the pack:

| Path | Role |
|---|---|
| `skills/scroll-world/SKILL.md` (~50 KB) | Full procedure: interview, stills, camera architectures A/B, seam rule, encode, assemble, QA |
| `references/scrub-engine.js` (~29 KB) | Portable, zero-dep vanilla JS: blob-seek scrub, seam crossfade, linger remapping, mobile seek-coalesce, iOS priming, `prefers-reduced-motion` stills-only fallback |
| `references/index-template.html` | Minimal standalone page that mounts the engine |
| `references/pipeline.md` | Copy-paste Monid / Higgsfield / ffmpeg batch scripts |
| `references/prompts.md` | Intake checklist + style-preamble / dive / connector prompt templates |
| `references/knockout.py` | Border-connected background knockout (PIL) for floating diorama stills |
| `.claude-plugin/*` | Claude Code marketplace / plugin metadata |
| `LICENSE` | MIT |

**What it is not**: a document-to-site converter. It interviews for a *new* brand story and generates AI art + video. That intent diverges from presentify's "existing files in, one offline interactive site out" contract - so adoption is pattern-and-engine extraction into presentify, not a wholesale skill import.

### Current-only strengths to preserve

## Presentify integration thesis

Treat scroll-world as a **RICH-mode upgrade and optional cinematic path**, not a second slash command that competes with presentify.

Recommended product shape for v3.16.5:

1. **Extend `--interactivity`** with a fourth level, or a named rich sub-mode: `cinematic` (alias: `scroll-world` / `fly-through`). Restrained / balanced / rich stay as today; cinematic = rich + a scroll-scrub stage when assets exist.
2. **Asset sources stay presentify-native**:
    - User-supplied local clips / stills (paths on the machine).
    - Tier 2 stock video (existing Pexels path) sequenced as short scrub segments where size budget allows.
    - Tier 1 procedural stills + CSS/SVG "flight" (Ken Burns / parallax stages) when no video is available - so cinematic degrades gracefully offline.
    - Tier 3 **local** AI stills as posters only - never hosted video generation.
3. **Ship a renamed, inlined scrub engine** under the presentify skill bundle (`references/scroll-scrub-engine.js` or similar), adapted so clips can be **base64 `data:` URIs or Blob-inlined** to honor the single-file offline guarantee (the source's multi-file `fetch(url)` must be adapted, not copied blindly).
4. **Do not** register Monid, Higgsfield, or Seedance as MCP / installer dependencies. Do not ship `pipeline.md`'s paid generation scripts into the catalog.

A separate standalone `/scroll-world` command is **not** recommended: presentify already owns interactive-site authoring, design intake, and offline guarantees; a sibling slash would split the surface and invite the forbidden generation pipeline to re-enter under a different name.

## Step 7: Risks, conflicts, and NOT-recommended items

### Conflicts and cautions

- **Offline single-file vs multi-file engine**: the source's `fetch(relativeUrl)` model breaks presentify's "one `.html`, zero external requests" guarantee if clips stay as sibling files. A2 must inline or Blob-embed; base64 video is heavy - gate cinematic on an explicit size budget (A6) and prefer short clips / stills-only when the budget is tight.
- **Job mismatch**: silently turning every presentify run into a brand diorama would violate presentify's document-faithfulness contract. Cinematic must be **opt-in** and must map extracted sections to scrub stages rather than inventing a parallel narrative.
- **RICH overlap**: cinematic should compose with, not replace, pinned-graphic scrollytelling. A report with charts still needs interactive charts; the scrub stage is an optional hero journey around or between content sections.
- **Attribution**: distributed artifacts must not name `scroll-world`, Monid, Higgsfield, Seedance, or Emons. Attribution belongs only in `docs/policy/mcp-reverse-engineering-matrix.md` (Reverse-Engineering Attribution Rule).
- **SKILL.md size norm**: all depth lands in references; do not inflate the presentify skill body past the soft cap.

### NOT recommended for adoption

| Item | Classification | Reason |
|---|---|---|
| Monid / Higgsfield / Seedance / Kling generation pipeline (`pipeline.md` paid path) | `drop-outright` | MCP Registry Policy **Hard-No: generation-as-service**. Also introduces credentials, outbound uploads of prompts/frames, and a new commercial relationship. |
| Shipping `/scroll-world` as a competing slash command | `drop-outright` | Splits the interactive-site surface; presentify already owns intake, offline HTML, and imagery tiers. Integrate as a presentify mode instead. |
| Claude plugin marketplace packaging (`.claude-plugin/`) | `drop-outright` (superseded) | Nexus-Hub's installer / integration registry already distributes skills to Claude and peers. |
| Defaulting cinematic on, or auto-spending on video gens | `drop-outright` | Conflicts with presentify's offline default and ai-billing-safeguards posture. |
| Hotlinking remote MP4s at runtime | `drop-outright` | Breaks offline guarantee; presentify never hotlinks. |
| Verbatim copy of SKILL.md / prompts that embed vendor CLI commands | `drop-outright` | Would reintroduce the Hard-No path as agent instructions. |
