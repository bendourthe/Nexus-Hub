# v3.17.3 Cursor Hook Portability Release Preparation

**Date:** 2026-08-16
**Branch:** `fix/v3.17.3-corrective`
**State:** Uncommitted release candidate

## Scope

This corrective release makes Nexus-Hub hook installation native to the host operating system and compatible with Cursor's hook response protocol. Windows installs and invokes the existing PowerShell hook siblings, while macOS and Linux retain the existing Bash implementations. The new Cursor-only adapter converts Claude Code's silent exit-0 success and exit-2 block conventions into a single Cursor permission JSON response, while preserving deny decisions and keeping human-readable diagnostics on stderr.

The release also carries the completed monitor fixes: live Codex Extra Credits payloads use `spend_control.individual_limit`, and lower-severity refreshes cannot overwrite an active high-severity warning color in either the Codex or Claude monitor. The v3.17.2 provider-state restoration migration is retained through v3.17.3 for delayed upgrades and deferred for removal to v3.17.4.

## Version Sequencing
