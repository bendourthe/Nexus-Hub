# Known Gaps -- v3.6.0

**Status**: v3.6.0 is in active development on `feat/spec-kit-delta-adoption`. The `adoption-spec-kit` plan (`docs/v3.6.0/plans/adoption-spec-kit.md`) is essentially complete: Phase 1 (skill-native doctrine folds N2a + N3b), Phase 2 (the `base-*.md` parity-governance guard, N3a), Phase 3 (N1a workflow-phase hook recipe), Phase 4 (the `/skills import` hygiene gate, N6), and Phase 5 (decline-durability) have all landed; only the final `/update release` step (version bump + tag + push) remains. Phase 4 was implemented ahead of Phase 3 at the maintainer's request -- the plan declares Phase 4's prerequisites as "None", so the two are independent; Phase 3 has now landed and NI-v36-1 is resolved. While building Phase 3, a pre-existing Phase 2 test gap was found and fixed (BG-v36-1, resolved). Phase 5 made the two deliberate declines durable -- N5 (authentication framework) and N1b (third-party extension install) now have authoritative `drop-outright` rows in [docs/policy/mcp-reverse-engineering-matrix.md](../policy/mcp-reverse-engineering-matrix.md) -- and logged the two deferred items (N4 self-upgrade CLI, N2b portable workflow engine) as DF-v36-1 / DF-v36-2 below.
**Last updated**: 2026-06-17 (adoption-spec-kit Phase 5)
