01 / The handoffs

Observation to queue to analyst to archive

Incoming field observations enter the queue. An analyst reviews queued observations, and approved records are archived. Approval belongs to the analyst-to-archive handoff.

Follow all three arrows. Only approved records proceed from analyst to archive.

03 / Evidence and source notes

Know what is established.

Current code and configuration

config.json and service.py are authoritative. The older generated handbook stated a retry limit of 2. The current retry limit is 3; capacity remains 24 and configured timeout remains 8 seconds.

Reliability unavailable

No reliability measurement is available. Configured limits do not establish a success rate, availability, or successful end-to-end execution.

Service boundary

The service loads its sibling configuration when imported. Its two helpers return the retry limit and compare the supplied queue size directly. They do not validate the input, enqueue observations, execute retries, enforce timing, review records, or archive them.

Handbook maintenance

The native build.py owns docs/handbooks/html/operations.html. Existing #overview and #workflow anchors remain available.

Inspect the complete configuration and service

service.py

import json
from pathlib import Path
CONFIG = json.loads(Path(__file__).with_name("config.json").read_text())
def attempts():
    return CONFIG["retry_limit"]
def admitted(queue_size):
    return queue_size < CONFIG["queue_capacity"]
