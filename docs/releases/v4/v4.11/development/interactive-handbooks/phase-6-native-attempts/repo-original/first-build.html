Evidence and limitations

Know what is established

The supplied service

import json
from pathlib import Path
CONFIG = json.loads(Path(__file__).with_name("config.json").read_text())
def attempts():
    return CONFIG["retry_limit"]
def admitted(queue_size):
    return queue_size < CONFIG["queue_capacity"]

CONFIG loads the sibling config.json when the module imports. The functions use that loaded configuration.

Reliability unavailable.

No reliability measurement is available. These settings and the described process do not establish a success rate, throughput or recovery time.

The supplied code implements a count lookup and an admission predicate. It does not implement a queue runner, retry execution, timeout enforcement, analyst review or archive storage.
