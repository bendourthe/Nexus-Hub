## Recommendation

Adopt five small skill-native edits, all inside existing owners: an earned-eyebrow gate and a frequency-of-use motion rule in `hallmark-design`, Kimi and Qwen prompting profiles through `model-prompting-research`, a generic OpenAI-compatible endpoint section in `multi-provider-ai`, and a native permission-deny pattern for spend-incurring commands in `ai-billing-safeguards`. Do not paste the user's restraint prompt into the instruction templates: Writing Discipline and Construction Discipline already carry the prose and code halves of it, and the eyebrow half is a UI rule that belongs in `hallmark-design`.

The cookbook is a vendor catalog of example apps against one hosted inference service. Almost none of it transfers as code. What transfers is the evidence that coding agents on Nexus-Hub's roster are routinely pointed at open-weight models, which Nexus-Hub's prompting profiles and provider guidance do not yet cover.

## Rejected Candidates and Limits

- **Context7 plugin, Exa, Tavily** (workshop settings and `integrations/tavily/`): hosted docs and search services on the MCP Registry Policy hard-no list (search-as-service; Upstash/context7 and Exa are named rejections).

- **Restraint prompt in all 13 instruction templates**: duplicates existing blocks (see Risks and Conflicts).
- **Lines-removed or net-diff metric** (I7): rewards churn and deletion for its own sake. `over-engineering-review`'s delete-list already names concrete removals.
- **`AGENTS.md` symlink**: the `@AGENTS.md` import already gives one source of truth, and symlinks need `core.symlinks` on Windows.
- **Single-ticket `/implement`**: contradicts the recorded whole-plan default. Its verifier discipline is already covered.
- **Inspect AI smoke recipe**: adds a dependency for a tier `skill-eval-loop` already has.
- **Per-model host guides as profile sources**: a hosting provider's guide is not the model vendor's documentation. They are used here only as evidence that the models are in use.
- **New platforms from `coding/README.md` (Cline, Zed, Cherry Studio)**: no decision record proposes them, and adding a runtime needs a VERIFIED read contract first. Out of scope.

Model claims in the cookbook (parameter counts, context windows) were not verified and are not used as facts here. No runtime test applies to this documentation-only report.
