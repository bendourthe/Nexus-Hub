## Memory Evidence Limits

The primary study evaluates seven methods and three models on one 419-turn conversation with 152 questions, one run per cell. It reports list-price costs including construction, while excluding the judge. Agents alone received photo captions; the photo-free subset differs by one answer between its leading agent configuration and full context. The paper therefore motivates a measurement protocol, not a universal ranking or a default model/harness choice.

For A1, freeze equal-evidence tasks and correctness criteria before trials. Compare full context when it fits, lexical retrieval, model-directed raw-file search, and extracted memory when reuse plausibly pays for it. Record writer and reader model/version, harness/effort, corpus revision, input availability, construction and update calls, cached and uncached tokens, retries, latency, quality, and operational cost. Keep evaluation/judge cost explicit and separate. A fixed-store monetary break-even estimate is `build_cost / (baseline_query_cost - memory_query_cost)` only when the denominator is positive; changing stores require an explicit update-cost model. Quality, access policy, retention and latency constraints can reject the cheaper method. No benchmark or efficiency improvement is claimed by this comparison.
