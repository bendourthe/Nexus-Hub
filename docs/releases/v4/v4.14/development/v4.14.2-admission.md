## Pre-registered evaluation rule (copied verbatim, dated 2026-10-20)

7. Evaluation: cap USD 40 covering every model call (Q5); it measures refactor-first and enumerate-every-copy, each with its own verdict (Q6); grading is deterministic from artifacts, with no grader model (Q7); both arms run `claude-sonnet-5-5` at its default effort (Q8). Reaching the cap before every run completes yields NOT_MEASURED; the run is never extended.

8. Verdict rule, pre-registered here and copied unchanged into the admission file before any run (Q9). Fixtures: three small repositories, each with one expression duplicated across three files (a pricing-style formula, a display format string, a numeric threshold), a passing test suite, and a task asking for a feature that needs that logic. Runs: 4 per fixture per arm (24 runs), plus up to 12 treatment re-runs in one revision round. A run passes refactor-first when its transcript shows a green test run after the last refactor edit and before the first feature edit, and the final suite is green. A run passes enumerate-every-copy when a search of the final tree finds the expression in exactly one definition and every original caller uses it. A rule is CHANGED when the treatment passes at least 4 more of 12 runs than the control; otherwise NO_CHANGE.

9. On NO_CHANGE for a rule: revise that rule's wording once within the remaining cap and re-run the treatment arm only; if still not CHANGED, keep it as low-cost guidance and record a known gap. Rules are never reverted on a negative verdict.

10. Evaluation isolation: each arm loads skills from its own git worktree (control at the baseline commit, treatment at the Phase 4 commit) with an empty home directory, and records the sha256 of every skill file it loaded; a control run fails if its loaded text contains the refactor-first anchor clause. Credentials come from `NEXUS_PILOT_ANTHROPIC_API_KEY`, mapped only into the child process environment.
