## Ownership-row schema (v4.14.2)

Quoted from `tests/skills/test_rule_ownership.py` at the baseline:

```python
@dataclass(frozen=True)
class Rule:
    rule: str
    owner: Path
    anchor: str
    owner_name: str
    non_owners: tuple[Path, ...]
```

Each row names a rule, the file that owns it, a distinctive clause of the rule (never its title), the token a non-owner uses to name the owner, and the non-owners. The aggregate test asserts the owner holds the anchor, and that every non-owner names the owner and does not contain the anchor clause. Four rows exist at the baseline: `refactor-first`, `design-invariants`, `prompt-cache-stability`, and `tool-call-decision-policy`.
