## Dispositions

| Finding | Decision | Evidence and boundary |

A separately approved scope policy with explicit historical debt accounting remains needed; this patch does not choose a repository cutoff. |
| 2. Honest failure counts reject test evidence | Confirmed; failure exception declined | `_tests_status` still rejects a section containing nonzero failures. Prose saying "pre-existing" and a green URL do not independently establish equal failures at a pinned baseline or that hosted CI ran the full suite on the candidate. Those need a structured, verified evidence contract. Existing negative tests remain applicable; this patch does not relax passing evidence. |

| 5. Immediate cleanup of recently active/detached work | Confirmed; automatic deletion exception declined | The existing completion and cleanup contracts require merged-and-idle checks and preserve detached trees. A run name or PR alone does not establish that a folder is unused. Bypassing those checks under an approval that displayed them changes destructive authority. This audit performs no deletion. A separate immediate-cleanup policy would need explicit displayed scope and clean/unused/merged proof. |

Evidence prose is not parsed as authority. |
| 7.
