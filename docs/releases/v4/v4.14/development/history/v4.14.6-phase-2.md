## Verification

- 112 tests in `tests/settings_control`, 30 in the catalog validator, 20 in the CLI file, 7 in the collection file; all pass. The `tests/ci` and workflow-policy roots pass. The full `tests/installer` directory result is in the admission record.
- The real-machine run changed no real file (three hashes identical before and after). Exporting `ANTHROPIC_MODEL` changed only the Claude model row.
- `show --json` output validates against the schema, and the schema rejects an unexplained or unknown state.

## CI impact

One new root collected on every operating system, no new dependency or variable, no pipeline file changed, no remote CI run. The installers need no edit: `scripts/lib` is copied as a whole tree.

## Deviations

- Phase 1's validator test lost its pure rules to `catalog.py` (the test imports them), because the engine must refuse an invalid catalog in an installed tree that has no proof matrix or `configs/`. The repository-only checks stay in the test, and its 21 original cases still pass.
- Six British spellings in Phase 1 files (`catalogued`) were corrected, because they became tracked files and failed the spelling check.
- Out-of-claim changes needed, not made: `docs/todos.md` (tick T012 to T016), and the `CHANGELOG.md` entry (due in Phase 3).
