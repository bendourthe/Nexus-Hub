## Plan delta

- **Effort rows are still Not-Settable** (paid probes were deferred by the maintainer), so `set effort` writes nothing today and exits 4 with each cell's reason. The writers are data-driven: the Verification Expectation and the effort tests use an in-memory copy of the catalog with the effort rows admitted, and admission decisions are unchanged. `remove-override effort --tool claude` is likewise refused until effort is admitted, because a removable override is allowed only while its control has an admitted write on that tool (the Copilot and Claude `disableBypassPermissionsMode` removals depend on posture, which is admitted for Claude).
- **New catalog data.** `catalog.json` gains a top-level `removable_overrides` list (three rows: Claude `env.CLAUDE_CODE_EFFORT_LEVEL`, Claude and Copilot CLI `permissions.disableBypassPermissionsMode`) and the loader validates it. The plan named the keys but gave the catalog no field for them.
- **Installer helper path.** The plan says to call the installed CLI core. At the point where core settings run, the installed copy may still be the previous version (the CLI is copied later in the run), so both installers call `$repo_root/scripts/nexus_hub_cli.py`, the same file about to be installed. Python resolution is inlined in the function so the existing function-extraction test harnesses keep working unchanged.
- **`--home` on `owned-keys`.** Added so an installer run against an explicit target reads the record beside that target; no other action takes it.
- **Marker scope.** An agent-session marker from any catalog tool refuses a weakening write for any tool, because the marker proves an agent is running the command, whichever tool the write targets. The same applies to a panel token.
- **TOML whitespace.** `tomlkit` normalizes blank lines in three cases outside the catalog's writes: the first top-level key in a file that has none, a created table, and a file with no final newline. A reset removes the key and leaves that one blank line or final newline. Every Codex write in the catalog is a top-level key, so the round trip is byte for byte for any file that already has a top-level key and a final newline.
- **Empty object spelling.** Removing the only member of an object written as `{ }` or `{` newline `}` restores `{}`.
- **Symlink.** This host cannot create symlinks without privilege, so the two real-link tests skip here; an emulated resolution test covers the logic and the Linux jobs run the real ones.
- **Windows owner-only.** Owner-only is a protected DACL naming OWNER RIGHTS, set through advapi32, which also removes access for administrators and SYSTEM until ownership is taken. The panel-token owner check is POSIX only.
- **Panel token residual.** A same-user process can write the token file, so the token stops replay and drift but not a forged token; the agent-marker refusal and the terminal test are the barriers (recorded in the contract).
- **Reset leaves an empty record file** (`{"entries": []}`) rather than deleting it.
