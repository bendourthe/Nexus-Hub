## Plan delta

**Incomplete (non-blocking).** The plan assumed every control could be observed in Phase 1. Effort cannot be observed without a model request, Copilot CLI is not installed, and the VS Code surfaces need a human, so only six writes are admitted. The rest are Not-Settable with reasons and a pending probe id. Consequences for later phases:

- Phase 2 resolves the 6 admitted writes and reports the Not-Settable cells with their reasons; a Not-Settable effort row cannot be written by Phase 3.
- Approving a one-token paid probe per effort key, installing Copilot CLI, and one VS Code sitting would turn most pending cells into controls without changing the engine design.
- The Phase 3 `owned-keys` helper must convert segment-array paths for the installers, whose seed record uses dotted keys.
- Codex `model` needs the validator's one named exception for the omitted-key rule.

## Deviations

- No sign-in files were copied into scratch homes (the plan allowed copying), because the observed fields need no credentials and a copy of a Codex `auth.json` risks the real sign-in.
- Out-of-claim changes needed, not made: `docs/todos.md` (tick Phase 1 tasks), `CHANGELOG.md` (entry is due in Phase 3), and a known-gaps entry for the unobserved cells and the new vendor keys (Phase 6, T038).
