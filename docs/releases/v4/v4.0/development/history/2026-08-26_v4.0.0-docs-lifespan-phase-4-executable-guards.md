## Troubleshooting

The first PowerShell guard run stayed silent because the script assigned stdin to PowerShell's reserved automatic variable `$input`. Renaming it to `$raw`, matching established sibling hooks, restored raw JSON input under Windows PowerShell 5.1.

The first full repository suite completed with 3,353 passes, 37 skips, and one failure. The three deliberate singular-archive fixtures did not carry an explicit legacy label, so the Phase 3 residual-path contract correctly rejected them. Adding exact `Legacy detection fixture.` comments and updating the Phase 4 exact allowlist resolved the integration failure. The final full run passed.

The first extension test pass also exposed an unrelated intermittent race in `nexus-memory`: one worker read the shared config while another wrote it and parsed an empty file. The exact test passed twice on immediate rerun, the full extension suite passed afterward, and the issue is recorded as BG-1 for the user-requested known-gaps reconciliation.
