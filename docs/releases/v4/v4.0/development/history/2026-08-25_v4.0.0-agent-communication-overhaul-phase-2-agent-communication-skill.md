## 2. Chronological Steps

### 2.1 Author the skill

**Plan specification**: Sub-task 2.1. Create the skill with a pushy description carrying verbatim trigger phrases and a SKIP clause, a body under 400 lines, a `references/response-contract.md`, and `evals/trigger-cases.json`.

**What was done**: Created `catalog/skills/developer-experience/agent-communication/` with:

- `SKILL.md` (159 lines). Description lists the six verbatim trigger phrases plus auto-trigger guidance for end-of-task reports, step sequences, command blocks, and non-technical readers, and a SKIP clause fencing off `writing-editing`, `anti-slop-editing`, and `markdown.md` mechanics. Body carries the seven contract sections condensed to numbered instructions, six Common Rationalizations (the four the plan required plus two more: "this turn is just an interim update" and "the style guide covers this"), a nine-item binary Verification checklist, and five Related Skills.
- `references/response-contract.md`. All worked examples: the three placeholder cases (derivable-not-derived, derivable-and-derived, unknowable-and-flagged) plus a multi-token REPLACE variant, the error-recovery re-issued-sequence example with the renumbering rule stated explicitly, the waiting-state bad/good pair, a worked end-of-task report, and a plain-language substitution table.
- `evals/trigger-cases.json`. Five positives and five negatives, exceeding the required 3 and 3.

The failure-mode requirement is honoured: the SKILL.md body states that when the style guide is absent (a consuming project without a full install) the body is complete enough to act on alone, and treats the guide as enrichment rather than a hard dependency.

### 2.2 Register the skill

**Plan specification**: Sub-task 2.2. Hand-edit exactly three data files; never run the builder.

**What was done**: Hand-edited `data/SKILL_INDEX.md` (row plus total 324 to 325), `data/skills.json` (full entry, category developer-experience, security 100/100/95), and `data/marketplace.json` (developer-experience `skill_count` 40 to 41). `data/marketplace.json` has no `total_skills` key in the current schema, so nothing there needed bumping. Bumped the declared "324 skills" figures in `AGENTS.md` (2 occurrences) and `README.md` (2 occurrences) by one, targeting the exact phrase rather than blanket-replacing numbers.

**Deviation**: a fourth registry file was required. `scripts/check_registry_entries.py --check --strict` failed with `unreachable: agent-communication bundles.json (in no module and no bundle, so only a 'full' install can ever include it)`. Added the skill to the `developer-experience` module in `data/bundles.json`, which is where its siblings `anti-slop-editing` and `writing-editing` sit. The plan's "exactly three files" instruction predates or overlooked this reachability gate.
