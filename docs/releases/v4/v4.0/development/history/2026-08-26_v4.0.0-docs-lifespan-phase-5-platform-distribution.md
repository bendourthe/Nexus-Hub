The plan required a global dry-run into a throwaway directory. The integration runner advertises `--target` as the global home root, but the base global renderer resolves home-relative destinations through `Path.home()` instead of `ctx.target_root`. The dry-run summary therefore named real profile paths. A subsequent isolated render attempt refreshed installer-owned Codex and Copilot surfaces in the real profile while placing only its manifest and summary in `%TEMP%/nexus-phase5-20260826-a7f34c`.

The newly inserted documentation block was removed from the user-level Codex `AGENTS.md`, preserving the existing managed markers and surrounding content. The manifest records all actions and checksums. BG-2 now tracks the deterministic root cause and the required regression test; it is assigned to the user-requested post-Phase-7 known-gaps pass.
