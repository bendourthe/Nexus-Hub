The first targeted registry synchronization exposed a defect in the legacy catalog builder: folded YAML frontmatter was read as the literal `>-`. `implementation-plan` was normalized to the repository's supported single-line frontmatter form, then its generated fields were re-synchronized. The same static pass caught and fixed an over-1,024-character `project-refactor` description and a stale capitalized index category.

The first full repository suite completed with 3,350 passes, 37 skips, and two failures. Both failures were v3.21 contract assertions that still required the singular archive path or older handbook wording. The assertions were updated to the canonical plural path and generalized living-reference rule; `/update release` was also made explicit about the complete handbook snapshot destination. A second full run then passed.
