## What this phase delivered

1. Added `link-baseline.py` to inventory unresolved relative links in every tracked Markdown file as sorted NDJSON and compare two baselines as `newly_broken`, `fixed`, and `unchanged` sets.
2. Added a native PowerShell 5.1 sibling with no-BOM writes and matching exit semantics.
3. Added a Tier-3 rename-map repair reference covering pre-move resolution, post-move re-expression, and the separate directory-prefix pass git rename detection cannot provide.
4. Added the `.gitignore` move pre-flight to `project-refactor` and the references-repaired evidence rules to `verification-before-completion`.
5. Added shared fixture tests that run the Python and PowerShell implementations in both directions, including the equal-total case and Markdown-code false-positive regression.

## Troubleshooting

The first PowerShell run failed because `--out` collided with PowerShell common parameters. Explicit script parameters fixed the binding. The second run exposed PowerShell function-output coercion, fixed by emitting parsed NDJSON records and building maps in the caller. The first whole-repo baseline then parsed a regex example inside Markdown code as a UNC link; both implementations now ignore fenced and inline code and the shared test contains that regression.

The complete `full` profile ran 42 commands. Forty-one passed; the repo test command reached its 3,600-second per-command limit with no failure output while the host was under concurrent test load. Classified `ENV`. Troubleshooting iteration 1 reran `python -m pytest tests -q` independently and completed successfully, so no gate was bypassed and no quality-gap entry was added.
