**Goal**: A Claude Code developer whose context window filled up runs `/usage context` (or one documented command on any OS) and sees which request and which tool call consumed it, located by time and tool ordinal, with exact totals and every estimate marked as one.

**Secondary outcomes** (deferrable under the cut-line, and not part of the single Goal check in the final phase):

- An agent answering an aggregate question over bulk data runs a script and prints only the answer instead of reading the data into context.
- The compressor records what it saved, and the report summarizes it.
- A raw `curl` or `wget` page fetch draws a one-line advisory toward the contained alternatives, without changing the permission decision.
- After compaction, the re-injected digest leads with the last request, open tasks and unresolved errors, and drops its lowest-priority lines first under the cap.

## Overview

This plan turns the five recommended candidates from its seeding comparison (A to E) into code and catalog text, in that comparison's reverse-engineer-first order, adjusted so the Goal ships first. Every item is a local rebuild or a rule: no outbound call, no credential, no new dependency. Nothing from either source project is installed, registered or copied; context-mode is under the Elastic License 2.0, so only ideas are adopted, and no distributed artifact names either source.

The center is candidate B: a standard-library report that reads a local Claude Code transcript and prints one row per model request. A request is identified by its request id, not by transcript record, because Claude Code writes one record per content block and repeats the same `usage` on each (measured on three local transcripts on 2026-10-13: about 2.6 records per request). Totals come from `usage` and print bare. Growth since the previous request is split across the tool results that caused it at about 4 characters per token and prints with `~`; whatever the split cannot explain prints as `~unattributed` rather than being forced onto a tool result. Rows are located by timestamp and tool ordinal ("Bash #12 of 30"). The report prints no transcript content: no prompt, tool input, tool output, thinking or path.

The report and its transcript reader live beside the existing usage probe in the hook helpers directory, so `/usage context` reaches them the same way `/usage` reaches `_usage_probe.py`, and so the Phase 6 digest helper shares the same reader instead of parsing the format a second time. The other phases are smaller and independent: the compute-don't-read rule with a measured eval (Phase 3), realized compressor savings (Phase 4), the raw-fetch advisory with a deliberate hook-contract change (Phase 5), and the post-compaction digest, gated on v4.15.1 (Phase 6).

## Definition of Done

1. `python ~/.claude/hooks/_context_report.py <transcript>` (and `/usage context`) prints one row per main-loop request with exact totals, `~` growth, `~unattributed` residual, timestamp and tool ordinal, and compaction and cut-off markers. Counts are grouped by request id, proven by a split-request fixture.
2. A fixture with one deliberately large tool result produces a top-N list whose first entry names that request and tool ordinal. This is the automated usefulness check.
3. No transcript content appears on stdout or stderr on any exit path, proven by canary strings in a tool result, a user message and an MCP tool name.
4. A malformed, empty or unsupported transcript exits 2 with a named error and never prints a partial table as complete.
5. The guide and the report both say which platforms are unsupported.
6. **Outcome criterion for A**: the Phase 3 paired eval records a measured delta, or records that the eval could not run and why. **A null or negative delta is a valid outcome and is recorded as such.**
7. Phases 4, 5 and 6 each shipped, or each is a known gap with its reason or its closed gate named.
8. Every rule added is stated in exactly one artifact; no distributed artifact names either source project or contains the literal `AGENTS.md`. The aggregate test proves it after every phase that edits catalog text.
9. `python scripts/ci/run.py --profile full` is green.
