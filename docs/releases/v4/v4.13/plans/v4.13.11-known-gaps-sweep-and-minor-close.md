## Overview

This patch repairs gap accounting first, batches small fixes by the files they share, and performs an additional locally grounded sweep of PLAN rows. A gap is closed only when its actual obligation is satisfied or a maintainer explicitly retires that obligation. Migration preserves unfinished work; it is never implementation evidence. The 31 QUICK rows are mandatory candidates to reverify, not 31 distinct code changes or promised closures.

Eight phases keep ledger work, hooks/tooling, skill/documentation, extension/guide/CI, dependency security, carry-forward preparation, and terminal verification independently reviewable. Phase 2 carries the greatest risk because parser changes, duplicate IDs, historical hashes, and approval snapshots must agree without falsely closing an item.

The archive order differs from the suggested sketch because the existing completion contract requires the last patch to have shipped. There is one implementation branch publication and PR, followed by release/back-merge and one administrative closing branch publication and PR. No release/archive guard is weakened to claim a single total PR. The closing branch is required even if no gaps remain to migrate. The plan-authoring PR requested in this session is separate from both future execution PRs.
