Findings and dispositions:

- **P2**: pointer eligibility accepted any `SKILL.md` in a shared VERIFIED path such as `~/.agents/skills` (another tool's skills). **Fixed**: eligibility now requires at least one catalog skill by name; `test_a_tree_of_only_foreign_skills_is_not_enumeration`.

- **P3**: template-identical text a user kept can be reported as a candidate. **Wording fixed**: the report now says "text ... that matches lines an older Nexus-Hub install shipped; review each diff, it can include lines you kept on purpose".
