## T405 and T406: GPT-6.1 Sol profile

- **The payload.** `build_payload.py` builds the 12-claim payload. A build stops if any quote is over 300 characters, is missing from the saved text after whitespace is collapsed, or matches the filter for agent-directed imperatives, tool-call syntax, and URLs off the allowlist. All 15 quotes passed.
- **The delegation claim.** The delegation prompt is recorded without its quote, because that quote is an imperative addressed to an agent. It is not adopted, for the same `agent-orchestration-primitives` reason recorded for `gpt-6-astra`.
- **The Astra delta.** `astra-delta.md` holds the delta against the 12 `gpt-6-astra` claims: 5 the same, 5 not stated for Sol, 1 different, and the delegation prompt the same but not adopted.
- **Roster.** The user approved one read-only OpenAI Models API call. It returned 133 ids including `gpt-6.1-sol` (`openai-models-roster.json`, ids only).
- **Roster decision.** The runbook requires the platform's own enumeration recorded verbatim, so the payload's roster is the `codex debug models` list from Codex CLI 0.136.0: `gpt-5.5`, `gpt-5.4`, `gpt-5.4-mini`, `gpt-5.3-codex`, `gpt-5.2`, and `codex-auto-review`. The writer unions it with the models already profiled for `codex`, so the recorded roster is those six plus `gpt-6-astra` and `gpt-6.1-sol`. The full API listing was kept as evidence only. The user chose this on 2026-10-01.
- **The write.** `write_model_prompting_profile.py write --input payload.json` wrote the `gpt-6.1-sol` entry and regenerated `references/models/gpt-6.1-sol.md` and `references/model-profiles.md`. It had passed a `--dry-run` first.
- **Checks.** `verify_model_prompting_profiles.py` reports 18 profiled models of 26 rostered, and the v4.13.8 `claude-sonnet-5-5` entry is intact.
- **The test.** `tests/skills/test_prompting_profile_gpt_6_1_sol.py` has 9 tests. A negative control failed the quote test when one quoted sentence was removed from the saved text.
