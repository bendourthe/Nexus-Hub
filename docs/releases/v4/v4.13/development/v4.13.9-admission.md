## T402 decision: Cursor handling of the command

**Choice: (b). Name the catalog command `visualize` and mirror it everywhere. Separately, fix the shared mirror's two collision defects in Phase 3, as approved by the user on 2026-10-01.**

**Evidence on shadowing (options a and c).**

- A `WebSearch` limited to `cursor.com` and `docs.cursor.com` (2026-10-01) found only discovery locations, "project commands in .cursor/commands/ at the workspace root and global commands in ~/.cursor/commands/". Nothing covered a user command sharing a built-in's name.
- Fetching `https://cursor.com/docs/agent/chat/commands` (no redirect) gave "not stated" for command storage, for name precedence, and for a built-in `/visualize`.
- The evidence is inconclusive, so the plan's rule selects (b).
- Neither (a) nor (c) is supported: no shadowing or duplication defect was shown.

**Evidence on the collision paths.** `scripts/lib/integrations/_command_surface.py::mirror_command_surface` is shared by Cursor (three call sites), Copilot, Pi, and Qwen. Reading it gives, for each required path:

| Collision path | Required | Observed | Verdict |
|---|---|---|---|
| A user's untracked `.cursor/commands/visualize.md` already exists | skipped as user-owned, never adopted or later pruned | the loop writes over any destination whose bytes differ (`dst.write_bytes(content)`), then `ctx.manifest.track(...)` adopts it | defect |
| A mirrored file the user edited, when the command later leaves the catalog | not deleted by a prune whose hash no longer matches | the prune unlinks every tracked stale file in the directory with no content check | defect |
| A manifest path that escapes the commands directory | ignored | the prune skips any tracked path whose resolved parent is not `dst_dir` | holds |

**Fix, to land in Phase 3 with the command.** The repository already has the primitive and the data:

- Route mirror writes through `_owned.write_owned_file(..., managed_root=dst_dir)`. It keeps any existing file the manifest does not record as ours and reports it as `kept`.
- Make the prune delete a stale file only when its current sha256 equals the one `manifest.record_actions` captured at install (`actions_for(key)`). Otherwise keep the file and untrack it, so it becomes user-owned.
- Add three collision tests to `tests/integrations/test_global_command_surface.py`, one per row above.

This is a safe-direction behavior change on all four platforms: a user file that used to be overwritten or deleted is preserved. It is recorded in the CHANGELOG.

This unblocks T412 and T414. The command file is `catalog/commands/visualize.md`.
