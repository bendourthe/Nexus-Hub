**Red check 1, `tests` (Linux), reopened the phase.** `hook-tests` failed one case: `test_hook_size_bound[learning-capture-sh]` reported a known breach that no longer reproduced. Classified as a test defect with a hook defect underneath. `learning-capture.sh` passes the payload to Python in one environment variable, which Linux caps at 128 KiB (`MAX_ARG_STRLEN`), so the oversized event is silently dropped rather than written whole. Reproduced locally in WSL Ubuntu (`/usr/bin/python3: Argument list too long`). Fix: the breach entry is gated `[not-linux]`. Verified under WSL (2 passed, 2 skipped) and on Windows (2 passed, 2 xfailed). The silent drop is filed as BG-14; no hook changed, as T423 requires. Every other check on the first push passed, including `tests-windows` (the Windows hosted runner finished `hook-tests` within its cap).

**Merge blocked by two CodeQL review threads.** With every check green, the merge stayed blocked on two unresolved `File is not always closed` findings in the Phase 2 helper `v4.13.9-sol-sources/extract_text.py`.
