## Troubleshooting

- The first draft kept SVG illustrations, but scaled SVG text would fall below the caption size in four narrow panels, so the illustrations were rebuilt from HTML parts with `data-ty="caption"` labels.
- The wire drawing first used `innerHTML` on the SVG; it now builds paths with `createElementNS`, which keeps to the project's no-innerHTML rule even though the values were computed numbers.
- The gauge used `max-width: 76px`, which the no-fixed-text-width rule rejects; it uses `width: 76px; max-width: 100%`.
- The static final frame left Platform A looking empty, so a dashed slot marks where the task started; the moving card covers it at the start of the animation.
- The first moment captures used viewport coordinates for a full-page clip and caught the handoff after it ended; the capture script now adds the scroll offset and pauses the panel's animations at a set time.
- Tests changed: `tests/guides/test_v41310_r44_r45_home.py` (R44 half rewritten for R47), `EXPECTED_HOME_ORDER` and the why-it-matters word count in `tests/guides/test_v441_phase2_home.py` (no Harness Benefits title; the count reads the benefit prose without illustration labels or platform names), and the eyebrow test in `tests/guides/test_v443_phase1_headings.py` (reads `#nhg-install`), the section-title count in `tests/guides/test_v442_phase1_foundation.py` (20 to 19); `tests/guides/tools/browser_matrix.py` keeps scrolling to `#nhg-benefits`, which is now the figure.
