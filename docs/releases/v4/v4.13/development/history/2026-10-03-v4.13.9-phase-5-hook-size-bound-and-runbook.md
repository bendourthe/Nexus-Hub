## What this phase was for

Bound the on-disk size of Nexus-Hub's own file-writing hooks with a measured, class-based test, and ship a runbook for the reported Codex CLI disk-write problem that states its fix version only as far as OpenAI's own sources support it.

## Phase entry

v4.13.8 was released on 2026-10-03 first, as the release order requires. `origin/develop` (with v4.13.8) was then merged into this branch (`5000ca1f7`), resolving count-only conflicts toward develop, rebuilding the legacy fingerprints, and combining the v4.13.9 ledger section; v4.13.8 WN-34 was carried here as WN-35, and the ledger header's open total was corrected (`70c4e19d8`).

## Steps taken

1. **T422.** Inventoried every catalog hook that appends to or rewrites a file, screened each for network and credential use, and measured 20 ordinary events plus one oversized and one multi-byte event in a temp root, for both the `.sh` and `.ps1` implementations. Classified each as bounded-rotation (`learning-capture`, `provenance-ledger`), append-only (`session-summary`'s log, `auto-devlog`), or intentional-overwrite (`session-summary`'s digest, `skill-tracker.py`). Skipped, with reasons: `usage-display`, `usage-guard.py`, and `_usage_probe.py` (network and credentials), `approval-capture` and `completion-gate` (write only during a bound run), `cursor-hook-compat.py` (writes only at install), and `lint-autofix` and `auto-format-on-write` (rewrite the user's own files). Record: [`v4.13.9-hook-size-bound.md`](../v4.13.9-hook-size-bound.md).
2. **T423.** Added `catalog/hooks/tests/test_hook_size_bound.py`: absolute per-class caps dated 2026-10-03, rotation hooks driven past a lowered cap, strict isolation (every home, app-data, XDG, and NEXUS path variable in the temp root, a temp git repository, provider keys removed, network blocked, real-home snapshots), and meta-tests proving the isolation guard catches a hook that escapes. Each measured breach is listed in `KNOWN_BREACHES` and asserted as a strict expected failure, so fixing a hook turns its case red until the entry is removed. Filed BG-13 (`auto-devlog.sh` drops entries after a line-1 heading), WN-36 (five hooks copy a field untruncated), and WN-37 (multi-byte inflation on Windows). No hook was changed, as the plan requires.
3. **T424.** Wrote [`docs/guides/host-agent-disk-writes.md`](../../../../../guides/host-agent-disk-writes.md) and listed it in `docs/README.md`. The fix version, Codex CLI 0.142.0, is verified by two OpenAI primary sources that agree: the `rust-v0.142.0` release notes (2026-06-22) list the persistent-log reduction citing #29432 and #29457, and #29432's merge commit lies between the `rust-v0.141.0` and `rust-v0.142.0` tags. Fetched text was paraphrased, not quoted. WN-3 is closed with that citation. The runbook shows no piped-install command and tells the user never to run an agent or Nexus-Hub command elevated.
