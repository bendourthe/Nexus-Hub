## Steps taken

1. **T014, the story model.** The story is `guides/website/src/training-story.json`, with a JSON Schema beside it (`training-story.schema.json`). `stamp_guide_shared.py` gained a `wrap` option, so the JSON is placed verbatim inside `<script type="application/json" id="nh-training-story">`, with no placeholder filling, and is refused if it contains `</script`. Fifteen stages: the intro, three plays, six loop-1 sessions, and five loop-2 sessions (loop 2 starts at review).
2. **T015, the intro.** The opening from Phase 2, with copy that no longer addresses the reader, matching the guide's rule.
3. **T016, both loops.** Each session is a short, coherent episode on a fictional `sky-sentinel` codebase whose bugs match the engine's defects. Loop 1 reviews the first-hit bug and records under "Not checked" that every run ended before 13 seconds. Loop 2's review finds a leftover self-test in `src/hazards.js` that fires after 20 seconds, and states why loop 1 missed it. Every command is a real catalog command with a real scope, which a test checks.
4. **T017, the sessions and badges.** `guides/website/src/training-story.js` renders a banner on every stage (step, title, and a "Now:" line), with the model badge (tier, effort, mapped model, reason, provider switch) on agent steps and the bug callout on plays. Each session shows a structured report (command, summary, headed sections, code, coloured diffs, pass/fail checks), the project file panel, and an agent activity log. Text is only ever set with `textContent`. A story missing a required field renders nothing and names the field in the page notice.
5. **Model ids come only from the map.** `scripts/stamp_training_models.py` copies the bundled map's tiers into a JSON block in the page, and its `--check` fails on drift, on a badge tier the map lacks, or on a provider that is not an exact map column. It was pulled forward from Phase 5, because the badges need it. Phase 5 adds its tests and CI wiring.
6. **Fixed by rendering.** The first captures showed four problems. Code lines rendered as separate chips, because the guide's inline-`code` style leaked into code blocks. Model ids wrapped. The play arena started about 550 px down. And a tall empty area sat beside short file panels. The fixes: a code-style reset, a wider model column, the play callout moved into the banner's right column, and measured column balancing. Each time a stage is shown, the renderer measures and chooses where the report's trailing sections and the activity log go, so the two column bottoms end closest, and the last card in each column grows so both end flush.
7. **T018.** Added `tests/guides/test_training_story.py`: the schema (when `jsonschema` is installed), stage order against the page, both loops, real commands and scopes, map tiers and providers, the two bugs as the game plays them, no second-person text, text-only rendering, each session's banner, badge, report, closed details, and activity, the play callouts and games, the provider switch (all badges, remembered, and working with storage blocked), no panel scroll bars, a file panel at least half the width, flush columns, file tabs by click and arrow keys, a long diff scrolling only inside its block, and a broken story naming its field.
