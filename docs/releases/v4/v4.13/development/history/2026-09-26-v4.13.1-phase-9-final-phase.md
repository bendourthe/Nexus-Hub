## Troubleshooting

### Each fix cycle opened a new hole

Cycle 1 made the hook stamp a clean check on every path a script mentions, which let a read-only script launder a user save. Cycle 2 counted a copy SOURCE as a write. Cycle 3 fixed that for Python, but PowerShell `-Path` still counts for reading cmdlets (BG-1). The lesson recorded for the follow-up: re-baselining must be tied to evidence of the agent's own write in a destination position, never to "the file was mentioned".

### Tightening the attribution footer lost real cases

Requiring a footer to end at the agent's name let "Generated with Claude Opus 5.5" and URL-suffixed footers pass. Cycle 2 restored them with model and version words and a short trailing clause, and cycle 3 settled the clause at four words.

### The runbook caps the deep pass at three cycles

The final re-probe still found BG-1. Its fix is small, but a fourth cycle is not allowed, so it is owned as the first item for the follow-up patch rather than fixed silently.

### Shell escaping kept corrupting patches

Several scripted edits broke on backslashes in regexes and Windows paths. Every later patch was written as a script file with the Write tool, or applied with the Edit tool.
