## Troubleshooting

- **Audit method**: a rendered audit compares each visible text element outside the exempt figures with a probe element of the same role and tone; the first run found about 670 mismatches in 90 groups, most of them colour, so the sweep gave the colourless roles explicit colours and moved colour variants into tones rather than adding a role per colour.
- **Hidden dash**: `shared/base.css` still gave `.fx-title h2` a teal colour and a dash `::before`; with the H2 size rules folded into the role, that selector would have turned the Foundations scene titles teal, so the selector was removed and only its layout kept.
- **Stray subtitle rule**: a Foundations-only `.page-lead` rule in the guide overrode the shared opening margin and colour; it was deleted so the three callouts compute identically.
- **Heredoc edit**: one follow-up edit was written as an inline Python heredoc and silently matched nothing because the shell rewrote its backslashes; it was redone as a script file, and the anchors now assert presence before replacing.
- **Phone callout**: at 390 px the balanced wrap and 24 px side padding broke the Training statement into five short lines; phones now use 16 px side padding and pretty wrapping.
- **Home statement size**: folding the page-title size into the H1 role grew the Home tagline, which also used the H1 role, from 36.8 px to 48 px; it now has its own `statement` role at the old size.
- **Tests on removed rules**: eight guide tests pinned what R27 to R30 removed (the `.inv-cmd`, `.cmp-side--without`, and `.cmp-side--with` rules, the bare `<summary>`, the unclassed scope `<span>`, the dash check on any `::before`, the `fx-pop` and `fx-draw` classes, and `.page-lead`); each now checks the replacement (tones, roles, the round dot, the shared subtitle class), and the dead classes left the markup.
- **Old-page check**: the new role, dot, scroll-visibility, and composer tests were run against the HEAD pages and fail there (95, 46, and 67 role mismatches on Home, Foundations, and Training; no H2 dots; 15 reveal elements on the guide; the legend shown before its segment; no Prompt row).
