## Troubleshooting

- The first smoke run listed a "Level 3" row with no spawns and no points after the test layer's jump to the boss; a level passed through with nothing spawned and no points now has no row.
- The first test of the clean universe expected the running upgrades from pickups dropped before the jump to the boss, but the jump's wormhole clears pickups; the test now collects them after arriving.
- The revive-expiry test first read the chip list from the state taken before the render; it now reads the state after it.
- The first details text for the Revive ("Once per level, second half; this level only") overflowed into the next column of the full key and failed the six start-screen fit tests; the details now read "2nd half; this level only" and "Last third of each level", and a new test checks that no key text spills at 1440 and 390.
- Existing tests changed: `test_both_pickups_drop_rarely` in `tests/guides/test_training_game_revision14.py` became `test_both_pickups_are_never_dropped_by_carriers`, because carriers no longer drop them by design; the victory title in `test_the_end_card_sits_in_the_centre_of_the_arena` (`tests/guides/test_training_game_engine.py`) is now "Victory", the keyword title the review asked for.
