# Comparison -- Harness Decisions, Design Rules, and Cache Stability

**Summary**: Four-source comparison (Gemini Skills launch and the `google-gemini/gemini-skills` repo; a custom decision harness built on the Pi SDK with a hosted scoring model; a published set of AGENTS.md design-principle rules with a refactor-first workflow; OpenAI's GPT-6 prompt-caching guidance) against Nexus-Hub v4.13.6. Read by the maintainer before `/plan from-comparison`. Key topics: refactor-first two-step rule, owning-module and duplicate-sweep invariants, decision-policy harness pattern, cross-provider prompt-cache stability, model-switch cache cost in `/implement`, Gemini consumer-app skills as a non-surface.

**Authored**: 2026-10-01, during the v4.13.6 cycle (in-flight release: v4.13.6, released; `develop` clean at `81d7e544e`).

**Adoption target: v4.17.12**

**Adoption-target reason**: Placed by the `plan-queue-assessment` placement rule on 2026-10-01 (first slotted at v4.18.1, the next free number, then moved after ranking). Every content predecessor (v4.15.1, v4.16.1, v4.16.3, v4.17.4, v4.17.9, v4.17.11) sits at or below v4.17.11; the queued v4.18.0 illustration plan shares no surface; v4.17.12 is the lowest free slot that sorts after all of them and fits the v4.17 harness-economics cluster. ## Step 5 Security and Reverse-Engineering Assessment

### 5.1 Threat model comparison

| Question | Source 2 harness as published | Nexus-Hub after adopting this plan |
|---|---|---|
| New runtime dependencies | Pi SDK packages, OpenRouter client | None (A8 is a bash and PowerShell hook pair with no new package) |

## Risks and Conflicts

- A1 changes the shape of `/implement` subtasks (two commits where one was usual). Conflict check: the plan-lifecycle rule requires ONE local commit per phase, so the refactor-first split must be expressed as two steps inside the phase (verified separately) that land in the phase's single commit, or the plan lifecycle must be amended. Recommendation: two verified steps, one phase commit; state this explicitly in the skill text.

- A5 edits a living policy doc; the queued v4.17.11 plan adds a note under the same step-8 table, so A4 and A5 must append beside it, not rewrite it.
