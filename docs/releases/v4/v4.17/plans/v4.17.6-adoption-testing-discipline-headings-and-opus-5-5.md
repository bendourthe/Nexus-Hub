**Goal**: An agent on any Nexus-Hub-supported platform writes tests before the code at the real boundary instead of backfilling coverage, and titles every generated document, deck, report, handbook, presentify page, and chat reply with Keyword Style headings rather than Full Sentence Style, with each behavior change shown by a paired before-and-after evaluation, and Opus 5.5 guidance recorded as a descriptive profile and an explicit effort-default decision, adding no new third-party destination, credential, or dependency.

## Definition of Done

**Must have:**

1. No distributed catalog file instructs an agent to add tests after the code to reach a coverage number: `grep -rn -i -E "[0-9]{2}%\+? (line |branch )?coverage|coverage (target|threshold|gate)|fail-under" catalog/` returns only lines on the Phase 2 diagnostic allowlist.
2. The keyword-heading bullet is present in `## Writing Discipline` on every substantive template in the directory-derived roster (13 at authoring), and `tests/validators/test_writing_discipline_rule.py` asserts it.
3. The sentence-heading detector reports recall of at least 0.9 and precision of at least 0.9 on a held-out fixture set not written into its tests.
4. A paired evaluation shows, on Claude, a lower Coverage Backfill count and a lower Full Sentence Style heading rate with the change than without it; other platforms are recorded as a known gap.
5. `profiles-index.json` carries a `claude-opus-5-5` profile in which every claim is classified descriptive or prescriptive, and no prescriptive claim alters harness scaffolding.
6. A decision record states the Claude effort default (keep `high` pending measurement) with a known gap naming the `v4.17.3` instrument.
7. The Testing Discipline block, the Run and Verify block, and the additional bad-stop wording each either ship on the roster within a line budget the user approved, or carry a dated known gap.

**Nice to have (cut in this order):** O8 routing `xhigh` vocabulary, O8 delegated finish line, O6 frontend defaults, O4 pasted-content marking.

## Non-Goals

- Hooks, the AI command guard, `nexus-hub add/remove`, the settings-merge contract, doctor environment checks, statusline presets, and the inventory analyzer. They move to the sibling plan `v4.17.7` because each needs a design pass (manifest schema, CLI routing, security constraints) that would otherwise hold these guidance fixes.
- Retrofitting existing Nexus-Hub documents to Keyword Style. The rule is forward-only.
- Changing the shipped Claude effort default. This plan records the decision; measurement waits for the `v4.17.3` instrument.

## Overview

The seeding comparison found one theme across four sources: the default an agent sees without a trigger decides its behavior. Nexus-Hub's only always-loaded testing text points agents at coverage numbers, no template states a heading style, and the Opus 5.5 guidance exists nowhere in the catalog. The user added requirement S1: every agent on every platform titles generated artifacts in Keyword Style and never Full Sentence Style.

The plan front-loads what does not wait on anyone. The widened testing cleanup (Phase 2) and the S1 heading rule (Phases 3 and 4) ship regardless of queued plans; S1 is a user mandate, so its one Writing Discipline bullet is not ranked against the `v4.16.0` cap. The optional always-loaded additions (T1, Run and Verify, O3) sit in Phase 6, late enough that `v4.16.0` has the best chance to have landed; if it has not, they become dated known gaps and the plan still publishes. Phase 7 proves the behavior changed, not only that text changed.

All work is local stdlib Python and Markdown. Phase 5 fetches public vendor pages through the existing prompting-research skill, and Phase 7 spends model calls on the user's own account under a stated cap; neither adds a destination, credential, or dependency.

## Resolved decisions

Recorded from the 2026-09-23 design interview (all recommendations approved by the user):

1. Adoption target v4.17.6.
2. Code-bearing items split to sibling plan `v4.17.7`, carrying three fixed security requirements: the AI guard never returns an allow, a settings merge never adds a permission, and item names are validated strictly.

#### 4.3 -- Sentence-heading detector

**Objective**: Make Full Sentence Style observable with measured accuracy.

**Failure modes**: Malformed or absent input (binary file, undecodable encoding, missing path, symlink, non-regular file, file over 5 MB): exit 2 with one stderr line, never a clean report.
