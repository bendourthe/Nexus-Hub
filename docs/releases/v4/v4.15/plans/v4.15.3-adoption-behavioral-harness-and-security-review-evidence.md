## Overview

Specialist security reports retain supporting receipts and uncertainty, while generic findings and the optional workflow template can reduce them to a location, confidence, and binary verdict. The primary user is the maintainer deciding which findings need action; the secondary user is the implementer reproducing a defect. This plan adds a thin local projection from the existing normalized security envelope, preserves that evidence through generic consumers, and exercises a synthetic cadence protocol using the evaluator planned in v4.15.2.

Four phases establish the projection, wire consumers, exercise the cadence protocol, then complete terminal validation and integration. Phase 2 carries the most risk: an incorrect mapping can suppress a security finding or overstate its proof. ## Definition of Done

1. A stdlib-only stdin/stdout projection delegates validation to the existing normalized-envelope owner and preserves dispositions, evidence/receipt identities, coverage, target bindings, health, and provenance without opening artifact paths or launching tools. Before evidence is associated with the current review, compare it against expected revision, root/scope fingerprints, and admitted run identity independently supplied by the review caller from its pinned context.
2. Generic review, its optional workflow template, and final-report preserve that evidence through merge, deduplication, filtering, and rendering. Missing runtime proof never silently becomes a security rejection or confirmation.
3. Legacy generic findings remain valid. Locationless security findings retain identity without fabricated paths or lines. Malformed, conflicting, or mismatched evidence produces an explicit failure/caveat, never a clean-review claim. Details absent from the pinned source schema stay explicitly unavailable; opaque IDs never stand in for a readable reproducer or observed execution.
4. Independent confirmed, static-only, pending, rejected, duplicate, locationless, malformed, and mismatched controls exercise the actual projection CLI and consumer logic. Evidence-drop mutations fail these checks.
5. A frozen cadence protocol runs through the actual landed v4.15.2 evaluator using credential-free fake adapters and an independent final grader. Synthetic results make no model-quality, savings, or default-change claim.
6. Fresh complete local, handbook, integration, known-gap, and native completion evidence supports every implementation-completion claim.
