## Recommendation

Fold eight items into v4.15.11. All are skill text or case design: no new skill, hook, script, dependency, or outbound call, and the plan stays at 38 tasks. Three items carry most of the value:

1. **Find the point before fixing sentences (D1).** The 0.13.0 release adds one step: state in one sentence what the draft wants the reader to know, and when that is impossible, rebuild from that sentence instead of repairing sentences. The v4.15.11 clarity reference checks sentences only, so a summary where every sentence passes and the whole says little passes it too.
2. **Shorter is not plainer (D2, D3).** The source adds a compressed-syntax family (noun stacks, verbed nouns, dropped *that*, a verb held behind a long list) and a guard that a rewrite which is shorter but slower to parse is worse. Nexus-Hub pushes hard toward compression (Output Minimization, a three-sentence limit per template rule), so a clarity rule without this guard can make prose denser.
3. **A cold reader, not a phrase list, catches change-relative text (D6).** The source measured three automatic checks for text that leans on a version the reader never saw. A phrase list fired 56 times with 0 real findings; fragment judges were unstable; a reader given the whole current text and no history found the real case. The v4.15.11 self-coined-terms case set should be graded that way.

Do not adopt the scripts or the hook. The structural reviewer posts draft text to the Anthropic or Gemini API, the ranker downloads a model and needs `torch`, the linter duplicates detectors other plans own, and the Stop hook fires every turn.

## Risks and Conflicts

- **D2 and the template size limit.** v4.15.11 allows each rule at most three sentences. D2 adds two words ("dropped *that*") to the clause T023 already plans; it adds no sentence.
- **D3 against Output Minimization.** The guard applies to prose a person reads, not to command output, which Output Minimization governs. T014 states that boundary so the two rules do not contradict each other.
- **D4 against Nexus-Hub's own vocabulary.** Plans and tests use "byte-identical" where a parity test proves it. The fault is the word without its check, so a cited check is the earned exception, and T014 says so.
- **D8 over-triggering.** A start-of-task description can pull `writing-editing` into code-only tasks. The SKIP clause, the existing trigger-eval gate, and the no-regression rule in `run_trigger_evals.py --gate` bound it. The change edits a file the plan already edits.
- **Attribution.** Catalog text from these items uses original wording and names no external project, per the Reverse-Engineering Attribution Rule in AGENTS.md. Attribution stays in this report.
