## Recommendation

Adopt nine items. All of them change existing owners, and none adds a dependency or an outbound call. Three gaps carry most of the value:

1. **Writing Discipline bans cliches but never asks for clarity.** Source 1 measured 78% of coding-agent samples as unclear, against 11% of Stack Overflow answers. It found the faults to be hidden actors and actions, vague wording, and empty statements, and it shows that cliche signatures do not predict them. The template self-check scans only the cliche list.
2. **No Fable 5.2 guidance exists anywhere in the catalog.** Fable 5.2 is the current Claude model. Its guide gives measured fixes for early stopping, silent turns, dense reports, and piled-up cautions. Nexus-Hub's `model-prompting-research` profiles have no entry for it.
3. **Template edits are never measured for behavior.** Every installed agent reads `templates/ai-instructions/`, but edits to it pass only parity and fingerprint checks. Source 4's core rule is to write the eval first and confirm it fails before making the fix. Nexus-Hub's own skills say the same thing, and its own process does not do it for templates.

Ship the codebase-ownership sentence only as an opt-in mode, as the user decided. It conflicts with the default rule that every changed line traces to the request, and in Anthropic's testing it raised output tokens by 70 to 80%.

## Risks and Conflicts

- **A7 against the trace-to-request rule.** `base-claude.md:79` says every changed line must trace to the request. The opt-in mode must state that it relaxes this rule only for related consolidation in the declared repository, and that the closing summary then lists every change, small ones included. Source 2 notes that summaries often left small changes out.
- **Template lockstep.** A1, A4, and A5 edit sections that exist in all thirteen substantive templates, and Writing Discipline and Autonomous Operation are byte-identical lockstep blocks. Each edit needs `scripts/build_legacy_fingerprints.py` and the doc-budget check, or `validate` and three test jobs fail.
- **Template size.** A1 and A5 add text to every session. Keep each addition to two or three sentences, and pair A5 with a merge into the existing Communication Contract bullet instead of a new bullet.
- **Hard style limits.** Source 2 warns that limits such as "20 words or fewer" make prose choppy. A1 must describe faults to avoid, not impose sentence-length caps. The opt-in STE register queued in v4.20.0 stays opt-in.
- **Later plans that touch the same ground.** v4.18.0 6.3 extends Autonomous Operation (after A4); v4.18.0 T003 adds the `anti-slop-editing` rule-ownership table; v4.22.0 and v4.22.9 T006 add structural and clarity cues ("noun clusters", "unusual word combinations"); v4.21.2 adds casewise eval comparison. Each must reference the owner that A2, A4, and A9 establish rather than restate the rule.

## Rejected Candidates and Limits

- **N1 Full "Finishing work" block, verbatim.** It adds about 30% output tokens and overlaps Autonomous Operation. Only the obstacle part (A4) is new.
- **N2 Ownership sentence as a default.** The user chose opt-in only on 2026-11-11, citing the conflict with the trace-to-request rule and the token cost.
- **N3 Harness reminder through mid-conversation system messages.** Nexus-Hub does not control the API harness of the platforms it installs into, and the one-line update rule (`base-claude.md:39`) already covers the prompt-side version.
- **N4 Hard STE or sentence-length limits in default templates.** Source 2 warns they make prose choppy. v4.20.0 keeps the STE register opt-in.
- **N5 LangSmith tracing, online evaluators, annotation queues, dashboards.** Rejected under the MCP Registry Policy; see the Reverse-Engineering Assessment.
- **N6 A slop-detector score as a clarity metric.** Source 1 shows detector and clarity scores diverge. A2 measures clarity separately.
- **N7 Source 3 wording and numbers.** They differ from Source 2 and omit the costs.
- **N8 Per-message effort and thinking-display API settings.** API features outside Nexus-Hub's instruction and skill surfaces.
- **Limit.** The Source 1 measurements come from the article's own annotation, and Nexus-Hub has no matching sample yet. A2's unclear rate gives the first local number.
