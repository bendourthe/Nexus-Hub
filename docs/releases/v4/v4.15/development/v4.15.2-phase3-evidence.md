## What the tests prove

| Gate | Evidence |
|---|---|
| Preflight fails before execution | Eight parametrized breakers (missing field, missing or unsafe adapter name, workload or evaluator hash mismatch, instruction figures, instruction path escape, duplicate pairing id), a missing binary, a credential-named environment variable, a string command, and an output collision all raise typed errors and leave no work or output directory. |
| Evaluator owns success | A `wrong-but-claims-success` adapter yields `harness_claim_success: true`, `evaluator_success: false`, `outcome: failure`. |
| Time budget and process tree | A hanging adapter that also starts a child is killed at its 2-second budget; the child process is confirmed gone. |
| Hostile bytes | Malformed JSON, invalid UTF-8, 200 KiB output, and non-allowlisted fields each become `adapter-protocol-error` and cannot assert success. |
| Canary secrets | A hostile adapter's secret-shaped, ANSI-bearing, heading-bearing, and HTML-bearing output, plus a secret in the parent environment, appear in no persisted file; the receipt passes the independent oracle. |
| Containment | An adapter that edits the evaluator's expected result is a `containment-failure`, never a success. |
| Interrupted run | Stopping after three trials leaves three schema-valid receipts and an aggregate marked `interrupted`; a re-run of the same id is refused. |
| Cleanup | Only a sentinel-owned directory directly inside the work root is removed; foreign, outside, and wrong-token directories are left. |
| Independent recomputation | The runner's aggregate for the six-trial matrix equals the oracle's recomputation from the same receipts. |
| Claude Code and Codex | `conformance` returned `ok` for both on this host (`--version` only, no credentials, no network; versions `2.1.318 (Claude Code)` and `codex-cli 0.136.0`). A host without the tools reports `binary-absent`, which the tests accept. |
| Guide and command line agree | Flags, exit codes, the constants (three repeats, 2000 resamples, z value, field cap) and the mode and tie-break sets are compared between the guide, the runner, and the oracle. |
