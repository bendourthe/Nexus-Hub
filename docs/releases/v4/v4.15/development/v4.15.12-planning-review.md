## Considered but Rejected

- Missing real-agent evidence: the plan explicitly separates oracle-only proof from the actual consuming-agent pilot, with load/effect receipts and an independent checker.
- Runtime, scheduler or parser expansion: the existing evaluator must be reused; missing capabilities block the pilot. A5 starts with manual local records and a worked table.
- Remembered approval as new authority: native approval remains separate; stale, forged, imported or conflicting permission text fails the relevant controls.
- Worktrees as security isolation: the plan explicitly rejects the equivalence and requires fake-tool-only capabilities without external mutation access.
- Per-phase remote CI or premature release: Phases 1-4 are local-only, every phase has one commit, and release follows approved green integration and smoke/provenance.
- Pilot budget escape: case, attempt, deadline, aggregate time and billing-enforcement preconditions are explicit; exhaustion leaves the phase incomplete.
- Final-phase unrelated cleanup: the required template is constrained to read-only scans outside this plan's actual changed surfaces, with exact coordinator claims before any extra write.
- Namespace differences breaking comparison: corrected trials require equivalent authoritative state rather than identical arm-specific identifiers. Deliberate within-case restarts retain original operation identity.
