The mark was restored; only the version line differs from develop, and the file parses with zero errors under PowerShell 5.1. The installer input digest and the manifest were refreshed again for the restored bytes.
- The DEVLOG summary was 213 characters against the 200-character limit; it is now 164.
- The interactive guide's mocked installer output still showed `4.14.8` in ten places across the Windows, macOS and Linux mocks; they now show 4.15.0, matching the installers.
