# v4.15.9 Platform Verification

Summary: release-time record for v4.15.9 that re-stamps the platform read contract from the v4.15.2 verification of 2026-11-16. No new vendor verification was performed for this release.

## Method

The [v4.15.2 platform verification](v4.15.2-platform-verification.md) re-fetched all 65 first-party URLs of the 17 integration groups and found no changed discovery path or format (3 groups unchanged, 13 unchanged with additive observations or wording changes, 1 unverifiable as recorded, none drifted). In the `v4.15.7..HEAD` range, the integration code changes only which agent frontmatter keys are withheld: a shared `CLAUDE_ONLY_AGENT_KEYS` list (`model`, `effort`) is applied at every non-Claude agent delivery path (`_catalog_adapters.py`, `base.py`, `copilot.py`, `cursor.py`, `antigravity.py`, `_kimi_native.py`), and Kimi keeps its existing `model` line, which Kimi documents ignoring. `catalog/hooks/settings.json` gains one Stop registration (`action-restatement-guard`) on a path already in the contract. The installers gain a PATH opt-out that does not touch any platform file. None of these adds or moves a platform read path, changes a file format, or changes a lever row.

## Result

`docs/policy/platform-read-contracts.json` is re-stamped with `last_verified` 2026-11-27 and `verified_for_version` 4.15.9. All verdicts, drift and unverified findings from the v4.15.2 record carry forward unchanged, as do its reading limits and the advisory lever review. The v4.15.9 plan's own fetch of the Claude sub-agents documentation (2026-11-21) is recorded in [`platform-defaults-levers.md`](../../../../policy/platform-defaults-levers.md) and is not a release-time re-fetch. No vendor application was launched or authenticated, so this record does not show that any platform consumed a Nexus-Hub file.
