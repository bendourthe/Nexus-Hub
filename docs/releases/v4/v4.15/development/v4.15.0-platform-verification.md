# v4.15.0 Platform Verification

Summary: release-time first-party documentation review of the delivered platform surfaces and advisory default settings, for reviewers preparing v4.15.0. Covers all 17 integration groups of the v4.14.8 review and the 17 lever rows. No read-contract group shows a changed discovery path or format; three groups carry observations and the OpenCode lever row changed.

## Method

Reviewed on 2026-11-12 against the [v4.14.8 platform verification](../../../../archives/v4/v4.14/development/v4.14.8-platform-verification.md) and its [v4.14.7 baseline](../../../../archives/v4/v4.14/development/v4.14.7-platform-verification.md), `docs/policy/platform-read-contracts.json` and `docs/policy/platform-defaults-levers.md`. Every first-party source URL in the baseline table and the lever rows was fetched again with the web-fetch tool on 2026-11-12. No page was unreachable and no URL redirected to a new host. Long pages (Claude hooks, memory, skills and sub-agents, Codex configuration reference, Qwen hooks and settings, Hermes and Copilot configuration) were read only in their first 100,000 characters, or in a second window where a key was missing from the first; findings come from the parts read. Page text is summarized by the fetch tool, so each observation below is a paraphrase of the page, not a verbatim capture, unless quoted. No vendor application was launched or authenticated.
