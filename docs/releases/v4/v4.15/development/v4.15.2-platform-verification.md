# v4.15.2 Platform Verification

Summary: release-time first-party documentation review of the delivered platform surfaces and advisory default settings, for reviewers preparing v4.15.2. Covers all 17 integration groups and 17 lever rows of the v4.15.1 review. No read-contract group shows a changed discovery path or format; 13 groups carry additive observations, and two wording changes (Antigravity workflows, Kimi project `AGENTS.md`) are recorded below.

## Method

Reviewed on 2026-11-16 against the [v4.15.1 platform verification](v4.15.1-platform-verification.md), which lists the observations carried forward, and the first-party source URLs of the [v4.15.0 verification](v4.15.0-platform-verification.md). Every one of the 65 URLs in that baseline was fetched again with the web-fetch tool in three delegated batches of 25, 24 and 16 pages. No page was unreachable and none redirected to a new host. Long pages were read only in their first 100,000 characters: the Claude hooks, settings, skills and sub-agents pages, the Codex configuration reference, the Hermes configuration page, the Qwen settings and hooks pages, and the first 200,000 characters of the Copilot configuration-directory page (the last 47,144 were not read). The Claude memory page was searched for paths only. Page text is summarized by the fetch tool, so each observation is a paraphrase unless quoted. No vendor application was launched or authenticated, so this review does not show that any platform consumed a Nexus-Hub file.
