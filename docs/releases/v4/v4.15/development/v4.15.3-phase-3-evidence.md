## Named dependency gap

The evaluator receipt cannot carry feedback timing, initial versus post-repair acceptance, counts, or spend provenance beyond cost, and its adapter output allowlist excludes them. The plan forbids modifying the engine here, so the matrix uses two adapter profiles and a sidecar history written by the fake adapter. The sidecar is scaffolding, not live evidence. Proposed known gap (coordinator delta): extend the pairing contract so a trial receipt carries these records before any live cadence study.
