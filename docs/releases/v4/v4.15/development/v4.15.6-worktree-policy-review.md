### Frozen Command Contract

Exit codes: 0 complete, 2 refused before any change, 3 partial or cannot verify. Refusal and partial results print a terminal JSON object with a `status` field.

- `path --repo <checkout> --name <name> --json` resolves and writes nothing.
- `create --repo <checkout> --branch <branch> --base <commit> --name <name>` creates through the resolver, serialized per repository.
- `list --repo <checkout> --json` shows registered paths and canonical destinations.
- `audit --machine --json --output <new-report>` is read-only discovery with a coverage ledger. A partial scan exits 3 and leaves a checkpoint for `--resume`.
- `migrate --dry-run --inventory <report> --manifest <new-file>`, then `--approve`, `--ack`, and `--apply --manifest <file> --expect-sha256 <digest>`.

Layout: `<root>/<repository-identity>/<worktree-name>`. The identity is the main checkout's folder name plus eight hex characters hashed from the canonical Git common directory. A name that changes while sanitized gets a six-character hash suffix.
