### Considered but Rejected

- Guide-only substitution: T015 executes the actual machine operations; T016 balances the initial survey and new discoveries.
- Treating 52 as exhaustive: coverage limits, skipped regions, refreshed volume discovery and newly created worktrees remain explicit completion inputs.
- Source-candidate migration mistaken for installed delivery: T013 requires independent review and exact-candidate qualification; Phase 4 does not overwrite installed helpers before green release.
- Missing phase commits, premature remote CI, or release before green integration: each phase records its local commit; only the terminal phase publishes, compares CI/CD, and hands green merged work to release.
- Identity based only on a folder name, copied mappings, or a native tool silently choosing another root: identity, ownership/collision refusals, adapter capability checks and visible uncovered surfaces are required.
- Deleting detached/dirty/locked work or forging native authority: explicit preservation, ancestry, owner handoff, per-item decisions and existing KEEP protections remain intact.
- A package-green result standing in for machine completion or prompt usability: final coverage, per-repository smoke, local receipts, independent prompt exercise and installed proof are separate gates.
