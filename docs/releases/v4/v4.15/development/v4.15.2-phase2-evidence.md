## Contract rules and where they are proven

| Rule | Proof |
|---|---|
| Missing identity or budget field rejects the manifest before execution | Eleven parametrized deletions plus a budget-field deletion. |
| Unavailable version, pricing, or tool-schema data marks the comparison incomparable | `manifest.partial.json` test. |
| Conflicting trial ids, workload hashes, or schema versions are rejected, not merged | Duplicate pairing id, schema version, and mixed workload hash tests. |
| Success is decided by the workload-owned evaluator | Forged-success and harness-claim mutations are rejected. |
| No successful task leaves cost per success unavailable, not zero or infinite | Dedicated metered-live fixture test. |
| Missing provider usage keeps success and latency and blocks cost | Synthetic receipts: every cost aggregate is an explicit unavailable object. |
| Three repeats, 95% Wilson interval, fixed-seed percentile bootstrap | Closed-form Wilson literals (2 of 3 gives 0.2077 to 0.9385) and a deterministic bootstrap test. |
| Different price dates or budget classes split comparison groups | Five split cases (pricing, cache, retry, concurrency override). |
| Recommendation restraint | Synthetic never recommends; fewer than three repeats, observational-live, and overlapping intervals each refuse; a separated metered-live fixture recommends. |
| Adapter bytes are hostile | Invalid UTF-8, oversized output, NUL, ANSI escape, forged heading, oversized field, secret-shaped values, non-allowlisted keys, path escape. |
| Instruction figures come from the one measurer | A bytes, hash, or token figure that disagrees with the file or `measure()` is detected. |
| Order and environment drift | A trial whose `order_position` or `workload_hash` differs from the manifest is rejected. |
