# v4.15.1 Platform Verification

Summary: release-time first-party documentation review of the delivered platform surfaces and advisory default settings, for reviewers preparing v4.15.1. Covers all 17 integration groups and 17 lever rows of the v4.15.0 review. No read-contract group shows a changed discovery path or format; ten groups carry additive observations and the OpenCode lever row now matches the vendor page.

## Method

Reviewed on 2026-11-15 against the [v4.15.0 platform verification](v4.15.0-platform-verification.md), which lists every first-party source URL, `docs/policy/platform-read-contracts.json` and `docs/policy/platform-defaults-levers.md`. Every URL in that baseline was fetched again with the web-fetch tool on 2026-11-15 (66 fetches in three batches of 25, 20 and 21 URLs). No page was unreachable and none redirected to a new host. Long pages (the Claude hooks, skills, sub-agents and settings pages, the Codex configuration reference, the Qwen hooks and settings pages, the Hermes configuration page and the Copilot configuration-directory page) were read only in their first 100,000 characters, or in a second window where a key was missing from the first; findings come from the parts read, and the Copilot page's last 47,000 characters were not read. Page text is summarized by the fetch tool, so each observation is a paraphrase of the page unless quoted. The reading was done by delegated fetch agents and spot-compared against the baseline wording; no vendor application was launched or authenticated.
