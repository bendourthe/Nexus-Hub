### 2.5 Add guide regression-test scaffolding

**Branch**: `feat/v4.2.0-interactive-guide-redesign` | **PR**: none | **Merged to**: not merged

**What happened**: Stdlib HTML parsing. Baseline: one document, unique ids, valid `data-go`, no runtime CDN, ZIP link. Redesign assertions use `pytest.mark.xfail(strict=True)` named by phase. First parser tracked Home via every tag and leaked past void elements, causing four XPASS failures; replaced with page-section depth tracking.

**Key files changed**: `tests/guides/test_nexus_hub_guide.py`

**Troubleshooting**:
- **Problem**: strict xfail tests XPASS because Home collection included Setup and later pages.
- **Root cause**: void tags never fire `handle_endtag`, so a tag-count depth never returned to zero.
- **Resolution**: track only `section` nesting for the current page.

**Verification**: `python -m pytest -q tests/guides/test_nexus_hub_guide.py` -> 7 passed, 16 xfailed.
