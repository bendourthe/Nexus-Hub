## Defects found and fixed via rendered QA

1. **GitHub octocat rendered as a crescent** - root cause was corrupted SVG path data inherited from v4.2.x (the user's screenshot-1 complaint), plus a CSS specificity trap (`.nav-links a` padding overriding `.nav-gh`). Fixed by replacing the path with the canonical 16x16 octocat and scoping the sizing rule as `a.nav-gh, .nhg-theme { ... padding: 0 }`.
2. **Hero measure mismatch survived the first draft** - `--measure: 62ch` resolves per element font size, so the H1 and lead still wrapped differently. Changed to a px-based shared measure (`--measure: 700px`) plus `text-wrap: balance` on H1.
