## Overview

v4.2.2 rebuilt the guide and is committed on `feat/v4.2.2-guide-cinematic-rebuild` with PR [#146](https://github.com/bendourthe/Nexus-Hub/pull/146) open and blocked. Maintainer decision (2026-08-29): **fold this work into the same branch and PR** rather than merging an interim UI that is already slated for improvement. The v4.2.2 stabilization commit `f4203850` (the `end-of-file-fixer` fix) ships with it on the first push of this plan's final phase. Nothing has ever been published, so no user sees an intermediate state.

Three decisions from the maintainer shape this plan. **Text width**: the per-text measure cap is removed entirely; body copy fills the content column at every viewport, driven by the container rather than by any px or ch value. **Framing**: teaching language becomes project-generic across all four pages -- "your project", "your files", "your work" replace "repo", "terminal", "git" wherever the sentence is explaining a concept. Factual product claims stay accurate: the hero still names the assistants Nexus-Hub installs into, and Training still demonstrates a real code example with real bugs, because inventing a non-code example would misrepresent what the downloadable ZIP contains. **Branch**: one branch, one PR, one merge.

Delivery is unchanged: one hand-authored self-contained offline HTML file, zero runtime network calls, the same 55-test gate extended per phase, and the Playwright render harness producing screenshot evidence before every commit. The file is 351 KB against a 500 KB budget, so the added illustrations have room.

Success looks like: the maintainer opens the guide and finds no item from the second review outstanding, and judges the result shippable.

## Phase 1: Fluid Layout, Copy Affordance, and Shared Conventions

**Goal**: Fix the three cross-cutting defects that appear on every page, so later phases build on corrected primitives instead of repeating the fix four times.
**Prerequisites**: None.
**Stability Gate**: At 1440 / 900 / 420 px in both themes, body text fills the content column with no per-text cap; every copy affordance is a bare icon with no surrounding chip inside another chip; page-nav buttons are sized to their label; the command/argument color convention renders in at least one place on Home; guide tests green.
**Recommended model tier**: strong
**Recommended effort level**: high
**Rationale**: Well-specified defects, but they touch every page's CSS and a change here that is wrong is wrong everywhere.

### Sub-tasks

#### 1.1 -- Remove the measure cap and make text fluid

**Objective**: Body copy fills the content column at every viewport width, with no hardcoded per-text width anywhere.

**Failure modes**: If the container query or `min()` expression is unsupported, text falls back to `max-width: 100%` (still fluid, never narrower than today). At very small widths the container's own horizontal padding is what prevents edge-to-edge text, so no text can touch the viewport edge. Wide elements that genuinely need a scroll container (the comparison table, code blocks) keep their `overflow-x: auto` wrapper so removing the text cap cannot introduce page-level horizontal scrolling.

**Build class**: load-bearing.

**Prompt**:
> In `guides/website/nexus-hub-guide.html`, delete the `--measure` token and every `max-width: var(--measure)` rule (currently on `h1`, `p`, `.lead`, `.fx-copy p`, `.nht-intent`, `.nht-takeaway`, `.wip-note` and any other consumer -- grep for `--measure` and remove them all). Body copy must then fill `.container`, which stays at `--maxw` and remains the ONLY width constraint. Maintainer decision 2026-08-29: no per-text cap, no `ch`-based cap, no fluid clamp -- the container alone governs. Keep `text-wrap: balance` on headings so titles still break sensibly. Re-check every page for a paragraph that now runs edge to edge without breathing room, and fix by adjusting `.container` padding rather than reintroducing a text cap. Verify no page-level horizontal scrollbar appears at 420 / 900 / 1440 in both themes. Render with `tests/guides/tools/render_guide.py --label phase-1` and inspect.

- [x] T001 Remove the measure cap so body text fills the content column guides/website/nexus-hub-guide.html
