A self-scan of the repository's own Markdown was treated as the phase's false-positive gate, and it drove three tunings before the detector was allowed to ship.

## The self-scan, and the three tunings it forced

The plan says a high false-positive rate on the repository's own prose is a phase blocker. The first scan found one.

| File | First scan | After tuning |
|---|---|---|
| `CHANGELOG.md` | 182 defect, 38 advisory (24 repeated-opener, 7 echoing-run) | 0 defect, 188 advisory (179 spaced-hyphen, 4 negation-chain, 3 repeated-opener, 1 echoing-run, 1 naming-ceremony) |
| `README.md` | 8 defect, 2 advisory | 0 defect, 10 advisory |
| `AGENTS.md` | 1 defect, 1 advisory | 0 defect, 1 advisory |
| the skill's own `SKILL.md` and `cliche-patterns.md` | 14 defect, 58 advisory (its quoted examples) | 0 defect, 0 advisory |
| v4.7.0 plan, Fable comparison, phase 3 history | 3 defect, 5 advisory | 0 defect, 3 advisory |

1. **The spaced hyphen became advisory, not defect.** Every one of the 182 CHANGELOG hits was a real clause-joining ` - `, so the regex was right and the class was wrong: that connector was this project's sanctioned ASCII replacement for an em-dash for years, the unicode gate does not police it, and a defect class that fires 182 times on legitimate history is one nobody will gate on. The Unicode characters stay defects because the strict unicode gate already rejects them.
2. **List items are excluded from the rhythm rules, and runs reset at blank lines.** The 24 repeated-opener and 7 echoing-run hits were consecutive bullet lines read as consecutive sentences; bullets are parallel by design. The three that remain are genuine same-opener runs inside one paragraph, which is the pattern.
3. **Matches inside straight double quotes or backticks are ignored.** The skill's own catalog and the phase 3 history quote the patterns they describe; a document that quotes a defect is not committing one. Both files now scan clean, and a test pins the behavior in all three forms (quoted, backticked, committed).

What remains on the repository's prose is advisory and mostly the legacy spaced hyphen, which is exactly the report a maintainer would want before deciding whether to clean it up.

## Plan delta

**Disposition: Incomplete (non-blocking, resolved inside the phase).**

Evidence: the plan defined the `defect` class as "chatbot leftovers and punctuation violations" without anticipating that the spaced-hyphen connector has a legacy footprint of hundreds of legitimate historical uses in this repository, nor that Markdown list items and quoted mentions would dominate the false positives. Its own 4.4 gate ("treat a high false-positive rate on the repository's own prose as a phase blocker and tune before proceeding") is what surfaced all three, so the plan's method worked while its class definition needed one adjustment.

Consequence for remaining phases: phase 7's Goal-vs-codebase review should read the detector's class boundary as documented in the module docstring rather than from the plan's one-line definition. No other phase depends on the detector.
