## The regression the full suite found

`catalog/hooks/tests/test_platform_parity.py::test_shared_rules_present_in_all_templates` failed on `base-claude.md` for the missing substring `Never hard-wrap paragraph text at a fixed column width`. That sentence was a bullet in the Claude-only `## Communication Style` section phase 1 retired when the rule moved into the shared block, where it reads `no hard-wrapping of paragraph text` and is present in all twelve templates. Classified IMPL (introduced by this plan, phase 1), because the phase 1 gates ran the validate target and the validators and skills tiers but not the hooks tier, which is where this cross-template pin lives. Fix: the pin now names the block phrasing, with a comment saying why; the module passes (4 passed). The eleven other templates still carry the old bullet in their own `## Communication Style` sections beside the block, so the rule is stated twice there; recorded as a note rather than changed, since retiring those sections was not in this plan's scope and would move eleven word counts.
