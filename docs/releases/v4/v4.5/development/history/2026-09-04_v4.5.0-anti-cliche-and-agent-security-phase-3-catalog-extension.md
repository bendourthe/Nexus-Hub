## The description change and what it taught

The first trigger-eval run failed one new case: "strip the chatbot leftovers like 'I hope this helps' and 'here is the revised version' out of this doc" routed to `known-gaps-tracker`, because the router is lexical and the skill's description never mentioned that class. Adding `chatbot leftovers`, `mannered prose`, and `the therapist-voice register` as trigger nouns to the description fixed the routing (366 characters, under the 1024 conformance limit). Two things worth keeping from the registry sync that followed: `check_registry_entries.py --emit` is the intended way to see what an entry should say, and the registry stores quoted frontmatter values with their surrounding quote characters included, so a byte-equal unquoted string reads as drift. The committed `summary_l0` line shows the same convention.
