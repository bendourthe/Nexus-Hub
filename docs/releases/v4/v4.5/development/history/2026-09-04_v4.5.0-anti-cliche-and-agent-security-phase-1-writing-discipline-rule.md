## Plan delta

**Disposition: Incomplete (non-blocking, resolved before implementation with maintainer approval).**

Evidence: the plan budgets the block in lines (14 maximum) and its Stability Gate requires `make validate` to pass, but `make validate` runs `scripts/validate_doc_budgets.py`, which enforces word ceilings on the five lockstep templates. Before this phase those files had 62 to 81 words of headroom; the block the plan specifies cannot be written in fewer than roughly 120 words while carrying the prohibition list, punctuation rule, chatbot-leftovers ban, and self-check it names. The plan never mentions the word ceiling, so Phase 1 as written could not pass its own gate.

Resolution: surfaced before any template was edited; the maintainer chose to author the block as tightly as its content allows and raise each ceiling by exactly the measured delta, rounded up to 10, with the justification the ratchet policy requires. The alternative (a 60-word block that names the rule and points at the skill) was declined because it would not carry the content the phase exists to distribute.

Consequence for remaining phases: none of phases 2 through 6 adds words to the templates (phase 2 adds guard configuration and a validator, not template text), so no further ceiling pressure is expected. Phase 7's cost reckoning must include the raised ceilings as part of what it weighs. No plan file edit is needed beyond the task ticks; recorded here rather than escalated.
