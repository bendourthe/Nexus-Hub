## 6. Assumptions Made

- **Inventory is the scanner denominator**: Schema v2 requires `scanner_inventory` so silent omission is mechanically detectable without hard-coding a scanner list into the gate. If a later phase needs a fixed catalog of scanner families, it should live in skill recipes, not in the parser.
- **Honest non-run receipts are clean when coverage is degraded**: `UNAVAILABLE`, `FAILED`, and `DECLINED` fail only when the record still claims `complete` coverage. This matches the contract that missing tools stay visible rather than blocking a scoped audit.
