## 2. Decision

The rejected decision at `docs/decisions/rejected/tooling/2026-08-24-typed-boundary-oxlint-vendor.md` selects option A. The existing `typed-boundary-hygiene` skill covers the intended agent behavior across supported platforms, while Nexus-Hub has no in-repo TypeScript application that can prove an ESTree visitor implementation or continuously exercise `@oxlint/plugins` API compatibility.

The durable out-of-scope entry at `docs/policy/out-of-scope/oxlint-in-nexus-hub.md` rejects both an Oxlint runtime or CI dependency and a catalog skill that vendors the plugin into consumer repositories. A later explicit decision must supersede this record before the capability can be reconsidered.
