## Why the old layout failed

Both prompts sat in a three-column grid, weak lane, sideways arrow, strong lane. In a full-width
scene that arrow pointed into empty space, which is what the review saw. The arrangement also asked
the reader to compare two paragraphs, when the useful comparison is between a prompt and the
specific things missing from it.

## What replaced it

The vague prompt keeps its own box and the flaws move beside it as four named items: no goal, no
material, no finish line, no shape. Each carries a red cross drawn as two rotated bars, because the
guide is ASCII-only and a cross glyph would fail the unicode gate, while four inline SVGs would cost
bytes for a shape CSS already draws.

The engineered prompt then takes the whole diagram width below, behind a downward triangle that
breathes rather than sitting still. Full width is not decoration here: it is the only width where
the four labelled parts fit one row, so Goal, Material, Done, and Format read as a set rather than a
two-by-two grid.

## Quieter, measured

The review called the active markers flashy. They were a 26 percent tint plus a full ring, which
reads as a button. They are now a 13 percent tint plus a rule under the words, which reads as a
highlight. The test asserts the box-shadow is inset rather than a ring, and that the marker never
signals state by fading its text, which is the v4.4.2 contrast rule.
