## What the README gained

Four v4.4.4 rules, each of them a thing this plan learned rather than a restatement of the diff:

1. The two pages use the heading pair in OPPOSITE orders on purpose. A Home label is a category, so
   it sits above what it categorises; a Foundations subtitle describes the scene, and the name is
   what a reader scans for, so the name comes first.
2. A model is named by family and by maker, with no version number. A family ages slowly and a
   version ages in weeks, and a static offline file cannot refresh itself.
3. An asset leaves the page when its teaching leaves. A 12 KB payload nothing explains is worse than
   no payload.
4. A sequence step is never hidden under reduced motion. This one reaches past motion: the contrast
   sweep samples only visible text, so anything hidden until played was never measured.
