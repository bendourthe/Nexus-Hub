## The ring

The operator called it a nonsensical circle with a dot and a triangle on it, and that is exactly
right: it depicted no step count, no duration, and no reasoning, and its own caption had to say so
("an illustration, not hidden chain-of-thought"). A figure whose caption exists to deny what it
appears to show is not carrying information.

What replaced it says the three things that are actually true of one request: it reads the request
and its material, runs both through the patterns it already has, and produces one output. Effort
appears as what it is, two bars where the higher one has more room on the middle step, with the
caveat kept verbatim because it is the reason the picture is allowed to exist. The steps light in
order through the shared sequencer and are all readable at once without motion.

Both scenes shared the ring, so both changed together; the Platform scene keeps a two-step variant.
The scene that grew as a result was rebalanced by stacking, since a six-stage vertical flow deserves
the full column rather than half of it.

## Press to play, inverted

v4.4.1 required a press before any motion started, and a browser test enforced it. The operator
asked for the opposite. The animation is now the element's own `src`, and there is no control to
press, which is also why the file got smaller here: the poster no longer appears twice and the
separate `data-motion-src` copy of the GIF is gone.

The half of the old rule that was about access rather than about asking is kept and asserted: under
`prefers-reduced-motion` the still frame is shown. Both assets still hash to the approved ledger, so
the approved-bytes discipline is untouched.

## Model names, read rather than recalled

The operator asked for up-to-date names from multiple providers. Naming a model from memory is how
a fabricated model id reaches a user, so the four names come from each vendor's own documentation,
fetched on 2026-09-03: Claude Opus 5 and Claude Haiku 4.5 (Anthropic), GPT-5.6 Sol (OpenAI, which
its own page calls its flagship), and Gemini 3.8 Flash (Google). The test asserts the names against
a declared list in the test file, so a future refresh updates the guide and the list together and a
drifted name fails rather than lingering.

## A pre-existing accessibility gap this phase exposed

With the ring gone, the hero lockup became the guide's only continuous animation, and it had no
reduced-motion state: a seven-second infinite float kept running for a reader who had asked for
less. The old assertion covered the ring, so nothing caught it. One rule added; the assertion now
points at the animation that is still there.
