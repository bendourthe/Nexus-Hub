## Sub-task 3.1 -- Title system and balance

The page-level `Foundations` kicker is gone. The h1 now reads `The concepts behind every AI-assisted project`, shares the `.hero-subtitle` rule with Home (same computed size and weight, gradient span, centred), and a centred lead states that the page explains terms and mechanics at a high level. ## Sub-task 3.2 -- Annotated-prompt primitive

`.ann-text` holds one continuous paragraph; `mark.ann[data-part]` spans carry a per-part colour (goal / request teal, material / context blue, done amber, format cyan) as a tinted background with a dotted underline; `.ann-legend` is a `dl` whose rows share the parts. A `NexusSeq` root reveals the parts in order and loops with a hold; under reduced motion every part and legend row is lit at once. The active part gains a stronger tint and a ring but never changes foreground contrast (the BG-13 rule). An unknown `data-part` falls back to a neutral colour; nested `.ann` is rejected by test.

Prompt Engineering keeps its vague card and arrow; the precise card is now the full improved prompt as one text with Goal, Material, Done, and Format marked and a four-row legend. Because the legend is a `dl` with the same four `dt` labels, the v4.4.1 `<dt>Goal</dt>` assertions stayed true without an edit. Context Engineering annotates the request and two attached-material clauses in the same way; the four context kinds and the two budget bars remain beneath.

## Specificity, twice more

Two first-run failures were both the v4.4.1 `BG-4` lesson recurring. A lone `.fx-stack` lost to the later `.fx-scene` rule on source order (same specificity), so no scene actually stacked; and a lone `.fx-subtitle` lost to `.fx-copy p` on specificity, so the eyebrow size never applied. Both are now compound selectors (`.fx-scene.fx-stack`, `.fx-copy .fx-subtitle`) with a CSS comment recording why, and the contract's deviations section records the recurrence.
