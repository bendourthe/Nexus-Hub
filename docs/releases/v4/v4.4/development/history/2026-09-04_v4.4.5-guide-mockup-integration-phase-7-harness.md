## A test that passed on a broken layout

The first run shipped the artifact chain as four full-width chips stacked one per line, which is not a chain. **The test passed.** It asserted that the left offsets were sorted, and four identical offsets sort perfectly well.

The cause is the specificity trap this project has now recorded three times: `.hx-row span { display: block }` has two components, a lone `.hx-chain` has one, and the lone class loses on source order regardless of what it declares. Every chain selector is compound now, and the comment above them says why.

The assertion is the more useful correction. It measures the property that actually failed: all four chips on ONE row, with four DISTINCT and increasing left offsets. **A sorted list is not a proof of order when the values can be equal.**
