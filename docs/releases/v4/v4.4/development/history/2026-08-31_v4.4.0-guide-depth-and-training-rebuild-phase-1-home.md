**Troubleshooting**:

- **Problem**: The first close-gate command passed the browser suite but then failed with `detect_visual_defects.py: error: unrecognized arguments: --page home`.
- **Attempted**: Rechecked the detector help and invocation contract.
- **Root cause**: The detector accepts the HTML file as its positional target and has no page-selection flag; Home is the guide's default active page.
- **Resolution**: Removed the unsupported flag and reran both theme sweeps plus every later command in the interrupted chain; all exited 0.
- **Problem**: Independent diff review measured the light-theme secondary verification numerals at 1.08:1 and the `Without Nexus-Hub` comparison label at about 3.3:1.
- **Attempted**: Traced the browser-computed colors through the theme cascade and alpha compositing rather than relying on token names.

- **Resolution**: Added a more-specific secondary numeral color, removed opacity from the comparison label, and extended the real-browser contract to require at least 4.5:1 for both numbered verification steps and both comparison labels in both themes at 320 and 1440 px.

## 5. Plan Discrepancies

The implementation preserved the phase outcome but corrected assumptions that would otherwise have produced incomplete evidence.

## Plan delta

**False assumption (non-blocking)**: The plan assumed the existing detector already supported both themes, the renderer could write release-specific evidence, and all six platform names could safely receive current standalone marks. In fact, the detector had no theme seam, the renderer hard-coded the v4.2 evidence root, and only three marks had verified usable geometry. Phase 1 added the two missing tool seams, used explicit text fallbacks for the other three brands, corrected the plan's numbering and terminal PR references, and recorded the remaining CI enforcement decision as MT-1. These corrections strengthen later phases without changing their order or product scope.

## 6. Assumptions Made

- **Trademark safety over visual symmetry**: A text treatment is preferable to a plausible but unsupported logo. If later official evidence changes, replace only the affected treatment and preserve the same accessibility contract.
- **Local browser availability**: The phase host has Playwright 1.62.0 and Chromium available; browser-backed tests run fail-closed locally through `NEXUS_REQUIRE_RENDER=1`.
- **CI changes wait for the terminal comparison**: Phase 1 records the clean-runner skip rather than adding browser installation cost before Phase 7 compares the complete pipeline.
- **Phase commit identity**: The Git commit containing this history file is the authoritative Phase 1 commit; no hash is fabricated inside the pre-commit evidence transaction.
