## Goals First and Definition of Done

The target user is a developer or reviewer following agentic work in any supported integration. The problem is missing a consequential limitation in a long update, or trusting a persuasive display or headline score without the evidence needed to decide. The observable result is a clearer agent response and a recomputable, locally rendered evaluation receipt. No project `STRATEGY.md` or `docs/solutions/` exists at authoring; repository purpose in `README.md` / `AGENTS.md`, existing owners and the comparison provide the available grounding.

1. **Communication**: An unresolved material limitation is visible beside the outcome with its consequence and evidence; a clean case invents no warning. Each retained positive diagram, plot and changed-workflow case meets its independently frozen representation expectations in all three candidate trials. Every candidate trial passes critical factual/risk assertions and simple cases add no inappropriate artifact.
2. **Behavioral comparison**: At least one preregistered target behavior improves over the unchanged baseline when admission confirms a baseline defect, without a critical factual/risk regression. Record all repeated runs, misses, costs and exclusions. If the existing baseline already satisfies an item, reuse it and make no redundant instruction edit. A small pilot verifies these cases only; it does not establish population-level improvement or improved human comprehension.
3. **Evaluation trust**: Existing fractional assertion scores retain their meaning. A separate whole-task binary endpoint has independent expected-outcome provenance. Valid matched cases yield both-pass, both-fail, gains and losses; inferentially eligible cases additionally yield specified paired-delta and per-arm success intervals. The handpicked pilot reports population inference unavailable. Missing, incompatible or unvalidated evidence cannot produce a green verdict.
4. **Report**: The existing benchmark JSON, Markdown and static HTML viewer agree. A compact SVG/data table shows uncertainty, regressions, sample/provenance, judge validity and cost per correct outcome. Missing spend and zero correct outcomes stay unavailable or undefined with reasons. Every displayed value recomputes from the retained receipt.
5. **Platforms**: A dated matrix derives its rows from the live integration registry. Observed native capability, documented capability and unavailable/unverified capability remain distinct. At least one real agent host exercises the changed communication and the offline portable route is rendered and inspected. Each additional claimed native surface has its own observed receipt; other hosts carry named gaps and a fallback, not invented parity.
6. **Delivery**: Complete the final phase's evidence, handbook and installer gates, independent Goal review and local suite. Implementation ends only on the completion checker's terminal result and the approved green integration flow, not on these authored checkboxes.

**Metric unit**: Preserve `grading.json.pass_rate` as the legacy fraction of assertions passed. An independently defined task outcome is an additive field, never derived by thresholding that fraction. Keep case ID, parent case ID, trial ID, arm, expected-outcome source, outcome evidence, model/setup pins and explicit validity. A duplicate, mismatched arm, absent grade or incompatible provenance blocks inference with its reason. A malformed file is reported, not dropped.

**Sampling and interval**: Select the preregistered first trial pair per independent case for inference; report repetitions separately for consistency, never as more independent cases. With N total eligible paired cases, gains g and losses l, delta = (g - l) / N. For joint confidence 95%, use two-sided 97.5% Clopper-Pearson intervals for each gain/loss binomial marginal (tail probability 0.0125), then delta bounds [Lg - Ul, Ug - Ll]. This conservative construction is a derivation from [exact binomial coverage](https://www.stat.math.ethz.ch/R-manual/R-patched/RHOME/library/stats/html/binom.test.html), [primary tail inversion](https://svn.r-project.org/R/trunk/src/library/stats/R/binom.test.R) and [Bonferroni simultaneous coverage](https://www.itl.nist.gov/div898/handbook/prc/section4/prc473.htm), not an optimal specialized matched-proportion method. Gain/loss marginals need not be independent of one another; paired cases must be independent samples of a defined target distribution for a population-coverage claim. For g = l = 0, bounds are +/-[1 - 0.0125^(1/N)], not [0, 0]. At N = 8 this is about +/-42.18 percentage points. The handpicked eight-case acceptance corpus does not establish a target-distribution sample: display its counts descriptively and population inference unavailable. Synthetic reference fixtures can verify arithmetic, never population efficacy. N = 0, numerical failure or absent assumptions/reference validation produces unavailable inference with its reason. No universal kappa cutoff, universal 12-point detection floor or nonsignificance-as-equivalence. Detection/non-inferiority claims require a separately specified margin, alpha, power/design and dependence justification, and are outside this pilot's claims.

**Per-arm interval**: For the same inferentially eligible independent-case endpoint, show each arm's verified binary successes k out of its explicitly stated N with a two-sided 95% Clopper-Pearson interval (tail probability 0.025). Reuse the validated bound function. Individual intervals do not replace the paired-delta construction. Fractional assertion scores receive no binomial interval. The handpicked pilot, absent/invalid binary outcomes, N = 0 or numerical failure produces unavailable population intervals with a reason.

**Cost**: Keep measured spend, dated price-based estimates and incomplete accounting distinct. Validate finite nonnegative monetary values and compatible currency/pricing units before aggregation. Negative/infinite/overflowing/mixed-unit or unconvertible receipts make cost unavailable with their reason. Whole-run totals cover both attempted successes and failures, retries, setup, helpers and graders; paired baseline/candidate arms are shown separately. Divide complete eligible spend by independently verified correct outcomes, with the numerator's run scope and denominator shown. The cost denominator is independently verified successful primary runs across the same attempted-run scope, including repeated trials; it is distinct from first-trial inferential N and the 3/3 behavioral-case gate. Helper/grader/setup spend enters the numerator with recorded allocation, never the primary-success count. Zero successes means undefined; incomplete cost or unvalidated correctness means unavailable. Never call a token count a dollar measurement.

**Behavioral pilot**: Freeze eight realistic cases before edits: two material-risk cases, two clean/simple cases, one architecture relationship, one measured comparison, one changed workflow and one unavailable-host or blocked-decision case. Use three fresh sessions per case per arm, at most 48 pilot runs, baseline first and candidate once; no favorable-result retries or expanding the holdout. An arm passes a behavioral case only when all three trials meet every frozen required expectation. A gain is a baseline-failing case that the candidate passes 3/3; a regression is a baseline-passing case that the candidate fails. Every retained positive diagram/plot/workflow case must pass 3/3, every candidate trial passes critical factual/risk assertions, simple cases add no needless artifact, and at least one real targeted baseline failure improves with no targeted case regression.
