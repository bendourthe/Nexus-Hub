# Known Gaps -- v3.7.0

**Status**: v3.7.0 (install-UX overhaul) is feature-complete on `feat/installer-bootstrap`. The `install-ux-overhaul` plan (`docs/v3/v3.7/plans/install-ux-overhaul.md`) has landed Phase 1 (self-fetching dual-mode bootstrap), Phase 2 (no-prompt all-platform install + conflict-only overwrite), Phase 3 (`nexus-hub upgrade` checker + CLI on PATH, un-defers N4), Phase 4 (interactive guide + install docs redesigned around the one-command flow), and Phase 5 (cross-platform CI verification + release readiness). Only the final `/update release` step (version bump 3.6.0 -> 3.7.0 + changelog + tag + push) remains. Phase 5 widened the CI bootstrap to a cross-platform matrix (`ubuntu-latest` + `macos-latest` for the bash path, plus a new `bootstrap-windows` job that runs the standalone PowerShell flow end-to-end), added a `nexus-hub --version` assertion to every bootstrap job, recorded a manual Mac smoke-test checklist (`docs/v3/v3.7/development/mac-smoke-test.md`), and resolved the personal-path leak that Phase 2 had deferred to the release (BG-v37-1).
**Last updated**: 2026-06-17 (install-ux-overhaul Phase 5)

This file tracks per-phase unfinished work, intentional deferrals, bugs, missing tests, warnings, and bypassed quality gates for v3.7.0. The next version's `/plan` ingests the open items here.
