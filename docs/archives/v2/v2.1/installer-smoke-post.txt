Test strategy
-------------

The plan's Phase 8.3 prescribes "scripts/installer.ps1 --target <throwaway-dir>
(or equivalent dry-target install)" verification. The installer does not
implement a --target flag (paths are derived from $HOME). Following the
precedent set in docs/archive/v2/v2.0/installer-smoke-post.txt, smoke coverage is
provided via deterministic pytest-driven assertions in
catalog/hooks/tests/test_installer_smoke.py plus targeted syntax-validation
runs. Rationale: (1) the pytest harness already runs in CI on every push,
(2) a real installer run depends on Node, VS Code CLI, optional extension
installs, and other side-effecting tooling that should not be exercised
inside a documentation phase, (3) the new artifact-distribution logic for
v2.1.0 is asserted via the same harness.

Result: PASS, 26/26 installer-smoke assertions green; 0 parse errors on
both installer.{sh,ps1} and the two new repo-level helper scripts.
