## Goal

A global install computes its manifest path under the user home (never the CWD), and any manifest-write failure degrades to a warning rather than a fatal traceback. This fixes the real user report of a `PermissionError [WinError 5]` traceback per integration when the one-line bootstrap runs from an elevated `C:\Windows\System32` prompt (the manifest resolved to `C:\Windows\System32\.nexus-hub\`).

## Sub-tasks completed

1. **1.1 - Scope-aware target-root fallback.** Added a single `_resolve_target_root(args) -> Path` helper with precedence: explicit `--target` wins; else `--scope global` -> `Path.home()`; else `Path.cwd()`. Replaced all nine inline `Path(args.target)... else Path.cwd()` occurrences (in `_template_vars_from_args`, `cmd_install`, `cmd_print_config`, `cmd_check`, `cmd_init`, `cmd_doctor`, `cmd_repair`, `cmd_list_installed`, `cmd_verify`) with the helper. `cmd_teardown`'s required-`--target` line was intentionally left unchanged. Subcommands without a `--scope` flag (init / doctor / repair / list-installed) keep their CWD default because `getattr(args, "scope", None)` is `None`, not `"global"`. Updated the `install --target` help text (it had wrongly claimed global was "ignored").
2. **1.2 - Manifest-write graceful degradation.** Wrapped `manifest.save(...)` in `cmd_install` and `cmd_teardown` in `try/except OSError`, emitting one stderr warning (`[warn] could not write install manifest to ...; install content is unaffected`) and continuing, instead of propagating a traceback and a non-zero exit. `PermissionError` is an `OSError` subclass, so the WinError-5 case is caught. The per-integration `failures` accounting is unchanged.
3. **1.3 - Tests, CI, changelog.** New `tests/integrations/test_runner_target_root.py` (7 tests) covering: global-scope -> home (and the derived manifest path is under home, not CWD); workspace-scope -> CWD; explicit `--target` wins for either scope; missing-`scope`-attr -> CWD; `cmd_install` global + foreign CWD writes the manifest under home and exits 0; and `InstallManifest.save` monkeypatched to raise `PermissionError` -> `cmd_install` returns 0 and emits the warning.

## CI decision (1.3)

No CI change was warranted. The existing `tests` job in `.github/workflows/ci.yml` already runs `pytest tests/integrations` on every non-docs change (changes under `scripts/lib/integrations/` and `tests/integrations/` are outside `docs/`, so they trigger it), and workflow-level `concurrency: cancel-in-progress` is already set. Adding a dedicated path-filtered job that re-ran `pytest tests/integrations` would duplicate the run and increase action minutes, directly against the plan's "keep action minutes low" goal. Phase 3.3 revisits CI holistically.

## Deviations
