## Context

Phase 0 restored skill loading, so the reorder is now observable. A real PDF run surfaced two coupled UX defects (Finding B): the design questions arrived far too late (the style prompt appeared only after extraction had begun) and only the style question ever appeared (layout / interactivity / imagery never surfaced), and separately the agent read a recalled `presentation-style-preference` memory and silently committed "Corporate & Professional" instead of asking. Root cause: the four choices lived in Step 4, after the expensive extract (Step 2) and figure-classification (Step 3) steps, as four separate sequential menus; and nothing forbade pre-answering from memory.

## Goal

The four high-level design choices (style / direction, output aspect, interactivity level, imagery tier) are resolved in a single batched round at the very start, before extraction and figure reconstruction; each still binds from its flag; NO recalled memory / saved preference / prior run / inferred context ever pre-answers a choice; the non-interactive fallback is preserved; and the generative token brainstorm stays after extraction.
