# Session History - v3.14.4 Phase 1: De-Codex the Claude Usage Monitor Extension

**Date**: 2026-07-18
**Plan**: [docs/releases/v3/v3.14/plans/v3.14.4-usage-monitor-split.md](../../plans/v3.14.4-usage-monitor-split.md)
**Phase**: 1 of 4 - De-Codex the Claude Extension
**Branch**: `feat/usage-monitor-split` (cut off `develop`)
**Status**: COMPLETE (non-final phase; no release-readiness workflow run)

## Goal

Revert the v3.14.0 "unified multi-provider" `claude-usage-monitor` extension so it monitors only Claude Code again - removing the Codex provider, the provider switch/config/dropdown, and every Codex render and recommendation branch - with the current UI intact and the Claude path behaviorally unchanged. The Codex-only monitor becomes a separate `codex-usage-monitor` extension in Phase 2.

## Approach (user-confirmed)

- **Surgical de-Codex**, not a hard git revert to 0.6.2 (preserve the current 0.7.0 UI).
- Collapse the provider abstraction to a single `ClaudeUsageProvider` while keeping the `UsageProvider` interface as the internal contract.

## Sub-tasks completed

### 1.1 - Remove the Codex provider and collapse the abstraction

- `git rm src/providers/codex.ts`.
- `providers/index.ts`: removed `createProvider` factory and `getConfiguredProviderId`; now exports `ClaudeUsageProvider` + `describeProviderError` + `./types`.
- `providers/types.ts`: dropped the `ProviderId` import/re-export; retyped `UsageProvider.id` to the `"claude"` literal; removed the `usage-unavailable` code (Codex-only) and the `providerId` field from `ProviderFetchError`.
- `providers/errors.ts`: collapsed to a single Claude `switch` (removed the `providerId === "codex"` branch and `describeCodexError`).
- `providers/claude.ts`: removed `providerId: this.id` from `fail()`.
- `types.ts`: removed `ProviderId`, `providerLabel`, `UsageMetricRow`, and the Codex-only `UsageData` fields (`providerId`, `planLabel`, `additionalLimits`, `creditsSummary`).

### 1.2 - Remove the provider switch, config, and settings dropdown

- `package.json`: deleted the `claude-usage.switchProvider` command and the `usageMonitor.provider` / `usageMonitor.codex.authPath` config.
- `extension.ts`: deleted the `switchProvider` command registration + constant + subscription, and the `usageMonitor.provider` config-watcher branch; `provider` is now `const provider = new ClaudeUsageProvider()`.
- `settingsPanel.ts`: removed the provider dropdown, the `setProvider` message handler + `onProvider` JS, the `setProvider` message type, and the `getConfiguredProviderId` import.

### 1.3 - Strip Codex render/recommendation branches + rebrand

- `recommendations.ts`: removed the two `providerId === "codex"` dispatch branches and deleted `buildCodexSuggestion` / `getCodexRecommendation` / `getCodexTips`.
- `statusBarManager.ts`: removed `providerIcon`; hardcoded `$(claude-icon)` + "Claude" label; dropped the `creditsSummary` tooltip branch.
- `dashboardPanel.ts`: dropped `additionalLimits` rows, the credits section, and the Plan-vs-Model branch (now always "Current Model"); header is "Claude Usage Dashboard".
- `warningView.ts`: removed the `providerId` field/param; hardcoded "Claude".
- `extension.ts`: hardcoded the Claude usage URL.
- `package.json`: `displayName` -> "Claude Usage Monitor", Claude-only `description`, version `0.7.0 -> 0.8.0`.
- `README.md`: rewritten Claude-only with a forward-pointer to the future Codex extension.

### 1.4 - Tests and stabilization

- `git rm` the three Codex test files (`codex-credential`, `codex-recommendations`, `codex-usage-mapping`).
- Trimmed `provider-errors.test.ts` to the Claude `describeProviderError` cases + a `ClaudeUsageProvider` identity test.
