## Overview

Phase 2 is the first user-visible change: both installers now render Phase 1's structured `--summary-json` as the mockup's per-platform checklist (fixed surface order Core Files / Skills / Commands / Agents / Rules / Hooks / Core Settings, green `[OK]` rows with the real install paths), print each vendor header LAZILY (only when the platform actually delivered), and collect platforms whose tool was not detected (Kimi/Qwen/OpenClaw/Windsurf/Aider-at-global/Copilot-without-VS-Code) into ONE "NOT DETECTED (skipped)" group instead of a colored header plus a caveat paragraph per platform. The previously-uncolored vendors (Kimi/Qwen/OpenClaw, plus Aider/Windsurf in bash) now have colors. The verbose per-platform caveat lines are gone.

## Sub-tasks completed

- **2.1 PowerShell checklist + lazy header + grouping.** Added `Write-ChecklistRow`, `Write-PlatformChecklist`, `Write-UndetectedGroup`, `Add/Reset-UndetectedPlatform`, and the canonical `$script:ChecklistSurfaces` order. Rewrote `Invoke-RegistryPlatform` to pass `--summary-json`, parse it (`ConvertFrom-Json`), print the vendor header lazily via a new `-Provider` param, render the checklist, or route to the group when no surface was delivered. Rewrote `Install-Global`: Claude renders the unified checklist (its bespoke helpers run under `6>$null` so their `Write-Host` chatter is suppressed with zero edits to the settings-merge functions), the 12 registry platforms use lazy-header `-Provider` calls, verbose caveats dropped, `Write-UndetectedGroup` at the end.
- **2.2 Bash mirror.** Added the equivalent `checklist_label` / `write_checklist_row` / `write_undetected_group` / `add`/`reset_undetected_platforms` (bash 3.2-safe: indexed arrays, `awk -F'\t'` parsing) and a `render_platform_from_summary` that extracts the summary via an inline `python` heredoc. Rewrote `invoke_registry_platform` (8th `provider` param, `--summary-json`, render) and `install_global` (Claude via `>/dev/null` + checklist; registry `provider` args; grouping). Suppression in bash is `>/dev/null` (stdout), which is simpler than PowerShell's `6>$null` because `echo` is not `Write-Host`.
- **2.3 Colors + grouping.** Added KIMI/QWEN/OPENCLAW to `Get-ProviderColor` (ps1) and AIDER/WINDSURF/KIMI/QWEN/OPENCLAW to `get_provider_color` (bash, with new `DARK_GREEN`/`DARK_RED` defs). Undetected grouping wired in both.
- **Bonus (Phase 1 code refinement).** The checklist immediately exposed that `_common_path` collapsed Codex's two skill roots to the useless home dir, and that command-skills nest a level deeper than plain skills. Replaced `_common_path` with a surface-aware `_surface_root` (trims each FileAction path to its surface directory) + `_join_distinct` (lists distinct surface dirs), so Codex's Skills row reads `~/.codex/skills, ~/.agents/skills`.

## Deviations

- `# DEVIATION:` Claude's checklist is rendered from post-install on-disk state (`Test-Path` / `[ -d ]`) after running its bespoke helpers quietly (`6>$null` in PS, `>/dev/null` in bash), rather than adding a `-Quiet` switch to each of the 6-7 print helpers. This achieves the mockup's unified checklist with zero edits to the fragile `settings.json`-merge functions (lower risk).
