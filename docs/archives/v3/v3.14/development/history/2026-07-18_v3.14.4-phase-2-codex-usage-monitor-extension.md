## Goal

Create a new, self-contained `extensions/codex-usage-monitor/` that mirrors the Claude extension's look and behavior, monitors only Codex, is fully rebranded (identity, assets, glyph font, `#5244BB` bars), and cannot collide with the Claude extension when both are installed.

## Sub-tasks completed

### 2.1 - Scaffold + seed the shared UI core

- Seeded the new folder from the pre-Phase-1 (multi-provider) git revision `984a606^` via `git show`, then stripped the Claude half to leave a Codex-only single-provider extension: sole `CodexUsageProvider`, `id: "codex"` literal, `providerId` dropped from the error type (kept `usage-unavailable`), `errors.ts` collapsed to Codex, `codex.ts` reads `codexUsage.authPath`, `types.ts` dropped `ProviderId`/`providerLabel`/`ExtraUsageInfo`/Claude model helpers and switched the config namespace to `codexUsage`, `recommendations.ts` collapsed to the Codex throttle/wait/rotate advice, `usageStore.ts` dropped the Claude-model reader and renamed the `globalState` keys `claude*` -> `codex*`.

### 2.2 - Brand assets + icon font

- Copied the user's `codex-white.png` into `icons/`.
- Generated `icons/codex.svg` (16x16 single-path monochrome glyph, pixel-faithful to `codex-white.png`) and `icon.png` (512x512 full-color, reconstructed from `codex-white.png`'s exact silhouette: cloud + periwinkle->`#5244BB` gradient + black `>_` knockout) with a one-off Pillow script.
- Retargeted the copied `generate-icon-font.js` to `codex.svg` / `codex-icons` / glyph `codex` and built `fonts/codex-icons.woff2`.

### 2.3 - Codex manifest

- `package.json` with a collision-free identity: `nexus-hub.codex-usage-monitor`, `codex-usage.*` commands, `codexUsage.*` settings (+ `codexUsage.authPath`), contributed icon `codex-icon` -> `codex-icons.woff2`, `codexUsageWarning` container + `codexUsage.warningActive` context. Version `0.1.0`.

### 2.4 / 2.5 - Rebrand + recolor
