## Context

Stock IMAGES need no setup (Openverse is keyless) but stock VIDEO is Pexels-only and needs a free `PEXELS_API_KEY`. Phase 3 spares the user from understanding that: a guided, opt-in, one-paste setup persists the key once and surfaces on first use and via a new `nexus-hub setup-media` subcommand. The honest limit is that we cannot auto-provision a Pexels key (it is tied to the user's own free account; a shared embedded key is a ToS violation and a secret hazard), so the helper guides the ~30-second signup.

## Decisions and deviations

- **DEVIATION (architecture): the subcommand dispatch lives in `nexus_hub_cli.py`, not the installer shells.** The plan said "dispatch `setup-media` in both installers in parity." The actual architecture centralizes the `nexus-hub` CLI in a single cross-platform `scripts/nexus_hub_cli.py` (the NI-v24-1 "one .py, no .ps1 sibling" convention); the native launchers (`nexus-hub`, `nexus-hub.cmd`) are thin shims, and `nexus_hub_cli.py` is a `scripts/` artifact both installers already copy. So `setup-media` is dispatched there (one file, cross-platform, mirroring the existing `verify` sibling pattern), and the only installer edits are the explicit-name copies of `setup_media_keys.py`. This is lower-risk (no duplicated dispatch logic in two shells) and consistent with the repo's convention; it fully satisfies the plan's intent (`nexus-hub setup-media` works cross-platform, wired via both installers).
- **Helper run as a subprocess, not imported.** `setup_media_keys.py` uses `getpass`, which must read the controlling terminal; running it as a subprocess with inherited stdio (like the pattern the CLI already uses) preserves the hidden prompt. The key is never passed as an argument (it would land in shell history) - the hidden prompt is the only input path.
- **`_resolve_pexels_key` uses `Path.home()` (not `NEXUS_HUB_HOME`)** per the plan's spec; tests monkeypatch `Path.home` to a tmp dir so the env-then-file resolution and the setup helper agree on the same path.
- **Two accepted by-design limits recorded** (DF-4: cannot auto-provision a Pexels key; DF-5: Windows 0600 is best-effort) and one deferred CI gap (QG-1: `tests/skills/` is not yet CI-gated; Phase 4.3 wires it) - I did NOT silently rewrite CI mid-phase.
