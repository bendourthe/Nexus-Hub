## Decisions and deviations

- **New dedicated CI workflow, not a step in `ci.yml`.** The main `ci.yml` uses `paths-ignore: docs/**`, so a docs-only comparison/plan misplacement would never trigger it. A separate `docs/**`-triggered workflow is the only place this check actually gates the relevant change. It is pure inline bash mirroring the skill snippet - not a `scripts/` artifact - so no installer copy-step or `.ps1` sibling is needed (per the plan's constraint).
- **Two-direction design chosen over a "does a plan exist" check.** The plan-side `**Seeded from**:` anchor plus the comparison-side `Adoption target:` placement check together catch all drift with zero false positives; not-yet-operationalized comparisons (no seeded plan) are correctly not flagged.
- **Body-only, no registry sync.** `documentation-consistency` has no frontmatter `version:` (footer convention), so per the plan's rule and the Phase 2 precedent, only the footer was bumped; no `data/skills.json` change.
- **Pre-existing 285-char description left untouched.** Not this phase's doing; already covered by WN-1.
