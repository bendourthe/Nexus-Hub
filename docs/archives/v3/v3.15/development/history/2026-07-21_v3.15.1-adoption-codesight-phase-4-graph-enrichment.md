## Goal

Add a file-level hot-file ranking (most-imported, a distinct labeled view from the symbol-level `code_impact`) and a git-scoped change map (`--since <ref>`: routes/symbols/models touched recently plus transitively affected tests), both derived from edges the graph already stores.

## Architecture

Both sub-tasks reuse the reverse-import machinery in `graph/affected.py` rather than adding new graph traversal, keeping resolution semantics consistent with `affected_tests`.

## Sub-tasks completed

### 4.1 - File-level hot-file ranking

- `graph/affected.py`: added `most_imported_files(conn, limit)` - inverts the same `_module_candidates` / import-node matching `affected_tests` uses (import nodes loaded once, matched in Python) to count inbound importers per file; returns `(rel_path, count)` sorted by count desc. Exported from `graph/__init__.py`.
- `model.py`: `hot_files` field on `ContextMapModel`; `GENERATOR_VERSION` 3 -> 4.
- `generator.py`: loads the top 25 hot files and renders the "Most-Imported Files" section (a `File | Imported by` table) with a note that it is a FILE-level view distinct from the symbol-level `code_impact`. Replaces the Phase 1 placeholder (resolves the outstanding half of DF-1).

### 4.2 - Git-scoped change map

- `contextmap/changemap.py`: `git_changed_files(root, ref)` runs `git diff --name-only <ref>` (None on bad ref / non-git); `compute_change_map(conn, root, ref)` returns a `ChangeMap` with changed files + affected routes (source/handler file changed) + affected models (source changed) + affected symbols (significant nodes in changed files) + affected tests (existing `affected_tests` BFS). Conservative.
- `cli.py`: `nexus-hub map --since <ref> [--json]` prints the change-scoped view and writes nothing under `.nexus/` (ephemeral, diff-dependent). Exit 1 on a bad ref / non-git tree.

### 4.3 - Testing

- `test_context_map_enrichment.py`: hot-file ranking (order, `limit`, exclusion of un-imported files, the filled map section) + change map (changed files, affected routes/symbols, transitive affected tests, bad-ref -> None, non-git -> None, both CLI `--since` output modes) via a real temp git-repo fixture. Updated the Phase 1 placeholder test to `test_most_imported_section_present`.
