## 2. Chronological Steps

### 2.1 Built the typed authorization broker

**Branch**: `feat/adoption-raptor-loop-hunt` | **PR**: N/A | **Merged to**: Not merged

**Plan specification**: Implement a standard-library-only Python broker whose pure authorization function returns either a least-privilege plan or specific denial reasons, with restrictive defaults and distinct exits.

**What happened**: Added `catalog/skills/orchestration/agent-access-policy/scripts/capability-grant-broker.py`. Its `Capability` enum defines `network`, `write`, `use_secret`, and `destructive_test`. Grants require an authorization source and typed scopes. Commands and scopes are defensively validated as non-empty string lists where required. Authorization makes no network call or process call. Execution is opt-in, requires a reachable sandbox prefix, builds a list argv, and invokes `subprocess.run(..., shell=False, check=False)`.

**Key files changed**: `catalog/skills/orchestration/agent-access-policy/scripts/capability-grant-broker.py`

**Troubleshooting**: A review of the initial parser found that `list(command)` would accept a bare string as a character list. The parser was tightened to require an actual list or tuple before authorization, preserving malformed-input denial rather than permissive coercion.

**Verification**: The CLI plan-only smoke test returned exit code 0 and an `authorized` payload with `sandbox_required: true`; the import audit found only Python standard-library modules.
