## Sub-tasks completed

### 5.1 - The visual-QA rubric reference

- `references/visual-qa-rubric.md`: the per-segment grading rubric assembling metrics from Phases 1-4 (full-width band, image sizing / crop / dead-space, annotation-overlay fidelity vs source, imagery integration, readability / layout), split into STRUCTURAL (scorer-checkable) and AGENT-VISION (screenshot judgment) kinds, with a per-segment score schema and a binary page-level pass bar (no open high-severity finding; n/a criteria and a correctly-degraded low-confidence annotated figure do not block). Documents the degradation contract.

### 5.2 - The fan-out workflow template (with degradation ladder)

- `assets/visual-qa-workflow.js`: a Dynamic-Workflow TEMPLATE (adapt, not run verbatim) with `export const meta`, a `pipeline()` over segments (grade vs rubric + source via a `FINDINGS_SCHEMA`, then adversarially verify each high-severity finding with an independent skeptic via a `VERDICT_SCHEMA`, majority-refute kills it), then synthesize confirmed fixes -> rebuild -> re-grade in a capped loop. Carries the three mandatory rules inline (graceful degradation, scope-first token caution with the 5-15x warning, skill-native no-outbound) and cross-links `[[agent-orchestration-primitives]]` + `[[ai-billing-safeguards]]`.

### 5.5a - The deterministic structural scorer

- `scripts/visual_qa_score.py` (stdlib-only, no network, headless-optional): scores a generated `.html` against the structural rubric subset (full-width band via the injected canvas vars; image caps; annotated-overlay well-formedness; imagery-integration count against a supplied expectation; offline / well-formedness) and returns per-criterion findings + the binary pass bar. The structural-review degradation path and the concrete realization of Phase 1's `measure_widest_band` "gate seed". Smoke-tested against a clean page + four seeded defects.
