## 6. Assumptions Made

- **Official API documentation is the Phase 1 authority**: No undocumented response field is treated as required, and additive fields must be ignored by later parsers.
- **Finding-only means unenforced**: Discovery of an upstream platform path does not authorize installer writes until a later phase defines ownership and lifecycle behavior.
- **Unknown allowance is not zero**: A missing denominator cannot yield a percentage, exhaustion state, or reset promise.
- **The 14x14 PNG is reference artwork only**: Without a high-resolution source and redistribution approval, it cannot become the packaged extension icon.
- **Focused verification is the honest Windows boundary**: The session records 130 passing affected tests and does not extrapolate that result into a claim about the incomplete 399-case integration run.
