## Scope decision (Hermes wiring)

Hermes is registered + documented + runner-installable (`runner.py install --integrations hermes`), but intentionally NOT added to the JSON `contract_checks` or the installers' default `should_install` / `known_platform_keys` wiring. Adding it to `contract_checks` would make `verify_platform_contracts` require an installer reference, and editing the installers is an AGENTS.md "ask first" action outside this phase's "no installer edit" scope. Hermes joins the aider/windsurf/openclaw tier (registered, documented, runner-installable). Full first-class installer wiring is tracked as v3.15.2 DF-2.
