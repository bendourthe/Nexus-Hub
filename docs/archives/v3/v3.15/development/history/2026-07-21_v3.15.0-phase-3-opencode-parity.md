## Overview

Phase 3 adds OpenCode's agents surface and resolves the plugins/hooks question (DF-4). Both sub-tasks were verification-led: a direct re-read of OpenCode's official docs confirmed the agents format before wiring and confirmed the plugins runtime before deciding. The agents delivery turned out to be config-only because the base `_mirror_catalog` already turns an `agents_subdir` config key into a verbatim `catalog/agents/` tree copy.

## Sub-tasks completed

- **3.1 OpenCode agents surface.** Added `agents_subdir: "agents"` to `OpenCodeIntegration.config`. The base `SkillsIntegration._mirror_catalog` copies `catalog/agents/*.md` verbatim to `~/.config/opencode/agents/` (global) and `.opencode/agents/` (project). A 2026-07-21 re-read of `opencode.ai/docs/agents/` confirmed OpenCode reads that path as `.md` + YAML frontmatter with the filename as the agent id and `mode` OPTIONAL (default `all`), so the catalog's 23 personas (`name`/`description`/`tools` frontmatter, no `mode`) load as-is - OpenCode uses `description` + the filename and ignores the non-native keys, the same way Cursor consumes the same files. No dead-path risk.
- **3.2 Plugins/hooks decision.** OUT OF SCOPE (documented non-gap, resolves DF-4). A re-read of `opencode.ai/docs/plugins/` confirmed plugins are JavaScript/TypeScript modules loaded by Bun that export functions subscribing to events (`tool.execute.before`, `file.edited`, ...); the docs state a `.sh`/`.py` script cannot be dropped in and run. Nexus-Hub's shell/py hooks do not translate without a per-hook JS/TS wrapper, so `hooks_supported` stays `False` (the base gates the hook copy on it) and no hooks surface is written.
- **3.3 Testing and stabilization.** Added `tests/integrations/test_opencode.py` (6 tests). Updated the contract JSON (parity block + `contract_checks` + `install_verify`) and the `.md` Re-verification log. Confirmed `verify_platform_contracts.py` still passes with the agents path added.

## Verification (2026-07-21 direct doc re-read)

- **Agents**: `~/.config/opencode/agents/`, `.opencode/agents/`; `.md` + YAML frontmatter; filename = id; `mode` optional, default `all`. Source: [opencode.ai/docs/agents](https://opencode.ai/docs/agents/).
- **Plugins/hooks**: JS/TS modules loaded by Bun, event-subscription API; shell/py cannot run. Source: [opencode.ai/docs/plugins](https://opencode.ai/docs/plugins/).
