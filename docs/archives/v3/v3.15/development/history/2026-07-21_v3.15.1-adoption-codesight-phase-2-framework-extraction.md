## Goal

Add framework-aware route detection (method / path / params / behavior tags), an env-var audit (required vs has-default, with source), and middleware detection over the tree-sitter graph, each feeding a section of the compiled context map and each fixture-gated for recall + zero false positives.

## Architecture decision (reuse-first)

The extension already ships extraction-time framework resolvers (FastAPI / Flask / Django / Express, built v2.2.0-v2.3.0) that emit `route` nodes with `name = "<METHOD> <path>"`, a `<framework>:` qualified-name prefix, and a `decorates` / `references` edge to the handler. Phase 2 therefore adds a read-only POST-graph analysis layer that reads those route nodes and enriches them, rather than duplicating framework parsing. Additional route frameworks (Hono / Fastify / Next / NestJS / Gin / Rails / Spring / Laravel) each need a new extraction-time resolver + fixture and are deferred per the plan's incremental posture (DF-3); ORM / component / event extraction is Phase 3.

## Sub-tasks completed

### 2.1 - Framework-aware route extraction

- `contextmap/behavior.py`: `infer_behavior_tags(source)` matches distinctive, word-boundary-anchored library/API tokens for auth / db / cache / payment / ai / queue / email; returns a fixed-order tuple.
- `contextmap/routes.py`: `extract_routes(conn, root)` parses each route node into framework / method / path / URL params (unions `{x}`, `<conv:x>`, `:x`, `(?P<x>)`), resolves the handler via the edge, and infers tags from the UNION of the handler's source and the route node's own span. The span fallback recovers tags for Express inline arrow handlers (no separate node); FastAPI relies on the edge-based handler slice. No resolved handler -> no tags (zero-FP safe).

### 2.2 - Env-var audit and middleware detection

- `contextmap/env.py`: `audit_env_vars(root, code_files)` scans real env-access forms (`os.environ[...]` / `os.getenv(...)` / `process.env.X` / `import.meta.env`), classifies required vs has-default (a call-site default or an `.env.example` declaration means not-required), and merges NAMES from `.env.example`-style files (never `.env`, never a value). Look-alike dict access is rejected.
- `contextmap/middleware.py`: `detect_middleware(root, code_files)` finds Express `app.use(...)`, FastAPI `add_middleware(...)`, and Django `MIDDLEWARE=[...]` registrations and categorizes each (auth / rate-limit / cors / validation / logging / error-handling / other) via a conservative name match.
- Generator: new Routes / Environment / Middleware sections + a `context/routes.md` article + an Overview `Frameworks:` line; `GENERATOR_VERSION` 1 -> 2; source fingerprint extended to cover `.env.example` files.

### 2.3 - Accuracy harness

- `contextmap/accuracy.py`: `evaluate(conn, root, truth)` scores routes / env / middleware against hand-counted ground truth, reporting per-section recall + a false-positive list; `SectionScore` exposes `recall` and `fp_count`.
- Fixtures `tests/fixtures/contextmap/{fastapi_app, express_app, django_app}` each with a `truth.json`; `test_context_map_accuracy.py` enforces a HARD zero-false-positive gate and a recall threshold per section.

## Deviations
