3. **Codex one-time setup.** On a fresh install, open Codex, run `/hooks`, trust the Nexus-Hub hooks, add write entries for one project and its `.git`, and confirm a full run commits (WN-5).
4. **A real GitHub repository.** Run one full plan against a throwaway repository you own to confirm the checker reads real pull-request checks and a real release, which the `gh` stand-in only imitates.
5. **Pause and resume.** Mid-run, tell the agent to pause; confirm the checker prints `PAUSED:` and that a later `/implement <plan>` resumes from the record.
