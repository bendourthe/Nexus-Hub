## Empty-space baseline (DoD 10)

**The plan's first measure was wrong, and this is the measured correction.** The plan defined an empty band as a vertical stretch of a section with no content. Measured that way, the current Training's tallest empty band is only 25 to 28 px at 1280 px, although the maintainer's screenshots show large empty areas. A capture of `#training-game` shows why: the emptiness is horizontal. The game card uses about two-thirds of the width with nothing beside it, and the file panel uses about half.

The corrected measure is the **largest empty rectangle** in a section. The section's content box (inside its padding) is laid on an 8 px grid. A cell is empty when no visible text run, image, SVG, canvas, video, form control, or box with a visible background or border touches it. The result is the largest all-empty rectangle of cells, as width by height in CSS pixels.

| Section | 1280 px (content width 1022) | 390 px (content width 316) |
|---|---|---|
| `training-game` | 312 x 1192 | 192 x 40 |
| `training-describe-review` | 512 x 312 | 120 x 96 |
| `training-plan` | 512 x 296 | 32 x 368 |
| `training-implement` | 512 x 320 | 32 x 432 |
| `training-fixed-game` | 312 x 1000 | 120 x 32 |
| `training-compare` | 312 x 632 | 96 x 56 |
| `training-presentify` | 512 x 336 | 112 x 32 |

Light and dark themes measure identically.

**Thresholds adopted for DoD 10.** A section fails when it contains an empty rectangle at least 25 percent of its content width wide and at least 160 px tall at 1280 px, or at least 50 percent wide and 120 px tall at 390 px. The current Training fails at 1280 px in all seven sections (the narrowest offender is 312 px wide, 31 percent, and 296 px tall), as the plan requires. At 390 px the current layout passes, because the phone layout stacks content in one column; the thin 32 px strips are panel gutters, not empty areas.
