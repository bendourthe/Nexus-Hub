# v4.13.8 Copilot organization connect: owner-account verification

The record of the maintainer's own Connect run on a real Business organization (plan task T343). It settles one fact GitHub does not document: whether VS Code's GitHub session with `read:org` can read the AI-credit usage endpoint, or whether Connect must fall back to the guided read-only token. The decision record amendment in [`2026-09-28-copilot-usage-monitor.md`](../../../../decisions/proposed/architecture/2026-09-28-copilot-usage-monitor.md) cites this file. The reading below answers it for the maintainer's organization: the token-free route did not connect, and the guided token did.

**Status**: run on 2026-10-03 by the maintainer; the guided token route connected (known gap v4.13.8 QG-9 resolved).

## What is being checked

| Call | Endpoint | Documented for a `read:org` OAuth session? |
|---|---|---|
| Seat count | `GET /orgs/{org}/copilot/billing` | Yes: "either the `manage_billing:copilot` or `read:org` scopes" |
| Pool used | `GET /organizations/{org}/settings/billing/ai_credit/usage` | Not stated: its page lists no token types or scopes |

Connect calls both with the session first. Both 200 means the token-free route works and no token is stored. Anything else means the guided token route. The extension logs each call's status code (never a token) in VS Code's Output panel, channel **Copilot Usage Monitor**.

## Steps (run as the organization owner)

1. Install the build from this branch. In a terminal, from the repository root of the `v4138` worktree:

    ```bash
    code --install-extension extensions/copilot-usage-monitor/copilot-usage-monitor-0.1.0.vsix --force
    ```

    Expected: `Extension 'copilot-usage-monitor-0.1.0.vsix' was successfully installed.` Then run **Developer: Reload Window**.

2. Before connecting, confirm the status bar reads `Copilot: --% (month)` and that hovering it explains the Connect step.
3. Run **Copilot Usage: Connect Organization**. Confirm or pick the organization, then accept VS Code's prompt to let the extension read your organizations.
4. Open **View** > **Output**, select **Copilot Usage Monitor**, and copy the line that starts with `Connect:`. It reads like `Connect: token-free route, copilot/billing 200, ai_credit/usage 200.` If it shows anything other than 200 and 200, follow the guided token steps that open, then copy the second `Connect: token route, ...` line too.
5. After the next refresh, compare the status bar's `Copilot: <pct>% (month)` with the organization's AI usage page, `https://github.com/organizations/<org>/settings/billing/ai_usage`. They should agree to within the rounding the dashboard notes (GitHub rounds to whole credits).
6. Run **Copilot Usage: Disconnect Organization**. Confirm the status bar returns to `Copilot: --% (month)`.

## What the result changes

- **Both 200 with the session.** The token-free route is confirmed. Record it here, cite it in the decision record, and resolve QG-9.
- **`ai_credit/usage` refused the session (403 or 404).** The guided token is the route for every owner. Connect already falls back to it, so no code change is needed. Record it, update the decision record's "Alternatives considered" (the token-free-only route stays rejected), and consider skipping the consent prompt in a later release, since it can never succeed.
- **`copilot/billing` refused the session.** The organization restricts third-party OAuth apps. Record it as organization-specific; Connect's fallback covers it.

## Other findings from the run

- **Expiry cap.** GitHub's page warned "The requested expiration (366 days) exceeds the allowed limit of 365 days for SupiraMedical" and fell back to No expiration. An organization can cap token life below GitHub's 366 days, so the pre-filled page now asks for no expiration, and the guided steps tell the owner to check the field.
- **Guided steps.** The steps vanished when Open GitHub was clicked, before they could be followed. They now say to read all four first, and a **Paste token** notification reopens the paste box.
- **Display.** The maintainer asked for whole-number percentages and for "Shared organization pool usage: X / Y credits" in place of "Pool: Y credits". Both are in the second amendment of the decision record.
