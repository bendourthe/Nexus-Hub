## Steps taken

1. **T001.** Measured the guide (487,805 bytes, Training about 103,800 of them) and inventoried every dependent test by class (old-engine only, durable behavior to retarget, incidental), every inbound link, the guide test timings, and the prerequisites. A search agent classified the test files; the classification is recorded in [`v4.13.10-inventory.md`](../v4.13.10-inventory.md).
2. **T001, the empty-space measure.** The plan's vertical-band measure found only 25 to 28 px bands on today's Training. A capture showed the emptiness is horizontal (nothing beside the game card or the file panel). The measure became the largest empty rectangle on an 8 px grid; today's Training fails it at 1280 px in all seven sections. The plan's DoD 10, Phase 1.0, and Phase 5.2 now state the corrected measure.
3. **T002.** Wrote [`2026-10-04-guide-training-as-a-second-offline-page.md`](../../../../../decisions/implemented/architecture/2026-10-04-guide-training-as-a-second-offline-page.md) and appended a dated amendment to the footer-attribution record, whose "travels alone" reasoning now covers two files.
4. **T003.** Carved twelve shared fragments out of the guide into `guides/website/shared/` (favicon, theme bootstrap, base CSS, footer CSS, type scale, Nexus mark, header, footer, theme, mobile nav, `NexusSeq`, constellation), each found by content anchors and wrapped in markers. The guide changed by marker comments only, proven by stripping the markers and comparing bytes. The header takes per-page link values, because the guide links in-page and Training links back across pages. `scripts/stamp_guide_shared.py` stamps and checks them and is listed in `DEV_ONLY_SCRIPTS`.
5. **T004.** Created the `training.html` shell: the stamped fragments, fifteen placeholder stages for both loops and the three plays, and a stage router with aliases, an unknown-hash fallback that shows a notice, and `#s-` in-stage anchors that never change the stage. A headless render with the network blocked showed the shared header with Training current, the footer, every route, the theme toggle, no console error, and no outbound request.
6. **T005.** Added `tests/guides/test_training_page.py` and `tests/guides/test_stamp_guide_shared.py`.
