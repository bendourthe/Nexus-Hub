## Troubleshooting

- The first install layout put the mockup beside the steps and the command box; the grid stretched the first row to the mockup's height and wrapped the command into three lines, so the walkthrough now stacks.
- The first phone layout put a 112 px illustration beside each panel's text, which made the Safety command unreadable; on phones the illustration now sits above the text at three quarters of the panel width.
- The mockup lines were first hidden with `display: none`, which would have shifted the page as output appeared; they use `visibility` so the window keeps its final size.
- The tab-switch test timed out: clicking a tab scrolls the tab row into view, which moved the new mockup off screen, so it correctly waited; the test now scrolls the mockup into view, and records each step with a MutationObserver instead of polling, which missed the 1.4 s paste step on a busy machine.
- The full run failed three existing tests: the installer's real restart line names OpenCode, which Home must not list (only the five approved platforms), so the mockup ends on the real "installed" message instead; the step numbers reused `vs-n`, which the verify-step count reads, so they use `inst-n` with the same look; and `max-width: 260px` on the phone illustration broke the no-fixed-width rule, so it uses a percentage.
- The full run also failed the "Nexus Hub without the hyphen" check: the mockup's label said "Nexus-Hub", now "Nexus Hub", and the mocked output quotes the installer, which prints "Nexus-Hub", so `.tm` joins the code and command carriers in `RENAME_EXEMPT_SELECTOR` (`tests/guides/test_v442_phase1_foundation.py`).
- Tests changed: `EXPECTED_HOME_ORDER` and the why-it-matters word ceiling in `tests/guides/test_v441_phase2_home.py` (now `Harness Benefits` and `#nhg-benefits`), the eyebrow test in `tests/guides/test_v443_phase1_headings.py` (reads `#nhg-benefits`; `ROLE_EXEMPT` gains `.hb` and `.tm`), the install-panel source test in `tests/guides/test_nexus_hub_guide.py` (numbered steps and the system icon instead of the one-line how-to), and the Home section group in `tests/guides/tools/browser_matrix.py`.
