## What this phase was for

Phases 2 to 7 built the checker, the gates, the runner, and the release chaining; nothing yet showed that a real agent, given `/implement <plan>` with the approvals up front, finishes a whole plan without an unplanned stop. This phase ran real paid sessions on Claude Code, Codex, and OpenCode against a fixture plan with a local remote and a `gh` stand-in, and decided whether the behavior changed. The full record, with every run, cost, and fix, is [`v4.13.2-e2e.md`](../v4.13.2-e2e.md).

## Outcome

- **Claude Code (condition A)**: 3 of 3 runs reached `PLAN COMPLETE` in the first turn, zero unplanned stops.
- **Codex (condition B, WSL Ubuntu)**: 1 of 1 run reached `PLAN COMPLETE` in the first turn; a second run was blocked by the OpenAI quota (MT-1).
- **OpenCode (condition C)**: a headless run cannot record approvals by design (WN-4); judged on safe stopping per the user's decision, it failed twice, proceeding on the in-prompt approvals (WN-7).
- **Verdict**: verified on Claude Code and Codex, not verified on OpenCode. The user chose to ship full-by-default on every platform with the gaps recorded, declining the fallback slice.
- **Spend**: USD 38.12 of the USD 50 first pass (Anthropic 29.13, OpenAI 8.99, the latter priced from token usage at published rates).
