Move Training out of the guide for good: every Training link opens `training.html`, the old Training leaves the guide, Foundations and Cheatsheets take the shared opening and outline, the sharing instructions cover two files, and every old Training test is either retired or pointed at the new page.

## Phase entry

Queue re-assessment: nothing landed on `develop` since Phase 1.

## Steps taken

1. **T028, the old Training leaves the guide.** Removed the Training page section, its scene JSON, the old engine and controller scripts, 108 Training-only CSS rules, and the nag-overlay rules. The guide went from 488,452 to 407,511 bytes (ceiling 500,000), including the openings added in step 3. No `nht-`, `nag-`, or `NexusTraining` reference remains.
2. **T027, links and redirects.** The router's `EXTERNAL_ROUTES` sends `#training` and every older `#training/<section>` hash to the matching stage of `training.html` with `location.replace`. The "Get trained" button, the nav tab, and the six "See it in Training" links open `training.html` directly. When `training.html` is missing beside the guide under `file://`, a probe shows a notice instead of a browser error page. `/compare` and `/presentify`, no longer taught in Training, became Cheatsheets entries.
3. **T042, shared fragments on Foundations and Cheatsheets.** Both pages now open with the shared opening (title, lead, tile map) and carry the sticky outline, stamped from `shared/` like `training.html`. The generic reduced-motion rules moved into the shared `motion-css` fragment. Two layout corrections fell out of the density check: the tile map became a wrapping flex row so six tiles fill one row and seven wrap as four plus three, and the outline resets the guide's global `details` styling.
4. **T030, sharing instructions.** The website README describes two pages, the `shared/` and `src/` folders, the new URL grammar, the Training story and engine, and a Training maintenance procedure. The repository README's guide section now says to share both pages with `assets/`. `example/training-scenes.json` was removed: nothing reads it after the test retirements.
5. **T029, tests and tools.**
    - **Retired** (they described only the old engine or sections): `test_arcade_shooter_game.py`, the six `test_v4134_phase*` files, `test_training_explorer.py`, `test_v441_phase6_workspace.py`, `test_v446_training_layout_followup.py`, and 16 old-Training tests inside `test_nexus_hub_guide.py`.
    - **Retargeted** to `training.html`: the publication check (no `script src` in either page, story inline in Training), the portfolio-copy check (both pages), command coverage (the story's six commands plus Cheatsheets), the parser fixture, the section-title scale, the 320 px navigation check, the legacy `?beat=` link (now a redirect test), the frame-loop lifecycle test, and the Phase 6 contrast, overflow, keyboard, and reduced-motion sweep (all 15 stages, both themes, six widths).
    - **Tools:** `render_guide.py` renders `training.html` for the `training` page. `browser_matrix.py` now targets Training stages with stage-owned regions; its pointer group became a running and an Escape-paused capture, since the new engine does not pause on pointer leave. Its guard test is `test_guide_browser_matrix.py`.
6. **Defects the retargeted tests found, all fixed:**
    - **The game loop never slept.** The shared Sky Sentinel loop requested an animation frame forever, about 60 wake-ups a second on every stage, including sessions with no game in view. It now runs only while a game is running; `start`, `resume`, and leaving manual mode wake it, and one pending request at most means a double resume cannot start a second loop.
    - **Contrast below WCAG AA.** File-status labels, check marks, and activity tool badges measured 2.1 to 4.2:1 in one theme or the other. They now use lighter tints on dark and deeper shades on light, each at least 5.4:1 on every background it sits on.
    - **File tabs lacked Home and End.** Added, per the WAI-ARIA tabs pattern the old explorer followed.
    - **The outline overflowed by 2 px at 320 px.** The summary's rotated chevron reached past its box; it now reserves that space.
    - **Dead markup.** `pg-outline-host` was a class no script or rule used; removed from the three hosts.
    - **Test helper.** The sweep's focus helper did not count `<summary>` as tabbable, so it skipped "Show technical details"; it now does.

## Review items for the maintainer (decision 17)

These are observations, not defects the plan names, and are left for the review of the finished page:

- **No next-stage control.** A reader moves between stages only through the outline and the loop tracker. A "Continue" button at the end of each stage would make the guided flow explicit.
- **The arena starts below the fold.** At 1440 x 900 the buggy game's arena begins about halfway down the viewport, and starting the game does not scroll it into view, so the ship is off screen until the reader scrolls.
