## What this phase was for

The maintainer, an owner of a Business organization, reported on 2026-10-02 that the v4.13.7 monitor showed "0.00 credits used this month" and "Not connected", and that Connect asked for a typed login and a pasted token with no link or steps. The maintainer approved folding a fix into v4.13.8: find the organization automatically, connect without a token when GitHub allows it, guide a pre-filled read-only token otherwise, and show only percentages. Source: `Nexus-Hub-worktrees/handoff-v4138-copilot-monitor-connect-and-percent.md`. This phase was added after the release PR #418 was opened; that PR is held as a draft until this phase merges.

## Phase-entry queue check

The v4.13.7 back-merge (`173c1c2d`) was merged first, and the v4.13.7 open gaps were carried under a `carry-gaps` approval before this phase was added. The v4.13.9 plan stays queued behind the v4.13.8 release.

## Steps taken

1. **T336.** Verified the GitHub and VS Code facts against official pages and amended the decision record: token-free first, guided fine-grained fallback, `expires_in=366`, percent-only display, with alternatives considered. GitHub documents no token-expiration response header, so no expiry warning was built; a 401 already offers Reconnect.
2. **T337.** `mapSeatOrganizations` and `fetchSeatOrganizations` in `src/providers/copilot.ts` read the seat's `organization_list` (valid logins and names only, no ids, never stored). `chooseOrganization` confirms one organization in a modal, offers several in a quick pick of `name (login)` plus "Other organization", and falls back to typed entry with a one-line explanation when there are none.
3. **T338.** Connect asks VS Code for the GitHub session with `read:org` and checks both pool endpoints with it. Both 200: only the login and a non-secret route marker are stored, and refreshes reuse the session silently. Any refusal logs both status codes (never a token) and falls back to the guided token; a network failure stops without asking for a token.
4. **T339.** The guided token is a modal with three steps and an **Open GitHub** button that opens GitHub's pre-filled page (`URLSearchParams`, `expires_in=366`, two read-only permissions), then a password box. Both endpoints are checked after the paste. A 403 or 404 names the three fixes and offers the organization's settings page.
5. **T340.** Status bar `Copilot: <pct>% (month)` or `Copilot: --% (month)`; hover and dashboard explain Connect; every used-credit line removed; the pool size remains. Disconnect returns the route so the message can say how to remove `read:org`.
6. **T341.** New `test/connect-flow.test.ts` (24 tests, including one end-to-end Connect, refresh, and Disconnect through the real controller). Existing tests updated for the new strings; the leak test now walks the new flow.
7. **T342.** Extension README, `package.json` descriptions, CHANGELOG `[Unreleased]` entry, and an Unreleased Capability usage block for "Copilot organization connect".
8. **T343 (prepared, not run).** Built `copilot-usage-monitor-0.1.0.vsix` and wrote [`v4.13.8-copilot-connect-verification.md`](../v4.13.8-copilot-connect-verification.md) with the steps and an empty reading table. Filed v4.13.8 QG-9 until the maintainer records the run.
