**Date**: 2026-09-26

## What this phase was for

Measure whether the fix landed: when a user edits a deck an agent produced, does the agent's next revision keep the edit and say so, with and without the hook, on Claude Code and on Codex.

## Steps taken

1. **T018: design before any run.** `docs/releases/v4/v4.13/development/v4.13.1-incident-replay.md` fixes four scenarios (A the incident path, B an edit between sessions, C a moved picture and new speaker notes, D the deck left open), three conditions (before, after, after with `NEXUS_DISABLED_HOOKS=user-edit-guard`), the measures, and the budget. The harness (`docs/releases/v4/v4.13/development/v4.13.1-replay/harness.py`, built from the Phase 1 spike) installs with the real installer into an isolated home per run, gives the pilot key only to the child CLI, and keeps every deck and transcript under `C:\tmp\v4131r`.
2. **Free install check.** Before the first paid run, both platforms were installed with the run's exact command and each installed hook was invoked from its installed location. It found two Phase 6 distribution defects, fixed before any run: `-Profile minimal` did not ship `user-edit-preservation` (now in the `core-developer` bundle every profile includes), and Codex's skills live under `.agents/skills`, which the hook's helper search missed (now searched, with `test_installed_layouts_find_the_helper`).
3. **Round 1** (one trial per cell, minimal profile): the incident reproduced before the fix (3 of 4 edits lost); after the fix 11 of 12 were kept, with one loss (Claude C with hooks) and five unreported edits.
4. **First fix cycle (maintainer decision: budget USD 45, full profile).** (a) The hook reads a script the command runs for quoted document paths: a recorded path that changed since blocks before the run, and the paths are recorded after it. (b) `edit_guard.py diff --against` compares with the agent's own copy when there is no record; the skill and all seven revision sections point to it.
5. **Round 2, trial 1** (full profile): the hook blocked the generator script's overwrite, but a hookless scenario C run still lost the edit after a by-hand timestamp comparison, and the hooked A run told the user the deck was "identical". The runs stopped for the maintainer.
6. **Second fix cycle (maintainer decision: budget USD 70).** The always-loaded rule on all thirteen templates now names `edit_guard.py check` and says an ad-hoc comparison does not count (same word count, block still at 260). Hook messages end with the exact `diff` command.
7. **Round 3** (scenarios A, B, C; three Claude trials per condition; five Codex runs): every edit preserved (18 of 18 Claude, 5 of 5 Codex). Reporting stayed incomplete: scenario B was never named, and no scenario C run named the moved picture.
8. **Post-round helper fix (tests only, not re-measured).** The diff now names each slide, sheet, or document body whose non-text content changed ("non-text change on slide 2 ...: tell the user about it").
9. **Verdict and gaps.** Not met as written (reporting); preservation met. Recorded in the replay record, and as WN-1 to WN-3 and MT-1 in a new v4.13.1 section of `docs/releases/v4/v4.13/known-gaps.md`. Round result files are committed beside the harness.

## Troubleshooting

### The minimal profile never installed the skill the rule names

The install check showed a hook registered with no helper behind it. Every instruction file names `user-edit-preservation`, so the skill now ships in every profile.

### Codex looks for skills in a different folder

The Codex install puts skills in `.agents/skills` beside `.codex/hooks`. The helper search now covers `../../.agents/skills` and `~/.agents/skills`.

### The settle window could have hidden the simulated edit

The harness made its "user edit" seconds after the agent's turn, inside the hook's 5-second settle window for the agent's own writes. The harness now waits 10 seconds, as a real edit would.

### Codex runs failed at setup in round 2

Round 1's folders could not be removed, so each round now uses a fresh work folder. The failed runs made no model call.

### A lint cache broke the docs-convention check

`ruff` left `.ruff_cache` inside the evidence folder, which `check_docs_conventions` rejects; it and a `__pycache__` were removed.
