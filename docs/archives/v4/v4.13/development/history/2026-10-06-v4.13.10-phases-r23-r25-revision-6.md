- **Capture coordinates**: the first figure captures mixed viewport bounding boxes with full-page clips and showed the sticky header over the figure; element screenshots with the header and the Training outline bar hidden fixed it.
- **Subtitle specificity**: the shared type scale sets `[data-ty="lead"]` later in the page than the opening CSS, so the new size uses `.pg-open .pg-open-lead[data-ty="lead"]` to win without `!important`.
- **Subtitle length**: the one-sentence check capped subtitles at 100 characters; the Training statement is 125, so the cap is now 130 and a separate test pins the exact Training text.
- **Stale dot count**: `test_phase6_verification_sweep.py` still expected three progress dots per guide page after commit `67a376513` added Training to the site order; it now expects one dot per page in `PAGES`, four in all.
- **Explorer width**: a three-column IDE leaves too little editor width between 720 and 960 px, so that band hides the explorer rather than shrinking the code.
