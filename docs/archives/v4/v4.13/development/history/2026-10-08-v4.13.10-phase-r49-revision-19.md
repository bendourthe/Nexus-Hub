## Scope

- T134 theme: every install mockup is a dark neutral terminal; PowerShell is #0c0c0c with the console's Campbell colours (Cyan, DarkGray, Green, DarkGreen, DarkYellow), macOS Terminal and GNOME Terminal are #1e1e1e with their own ANSI palettes; the blue PowerShell body and the aubergine GNOME body are gone.
- T134 chrome: PowerShell keeps the "Windows PowerShell" title bar with minimise, maximise, and close on the right; macOS keeps the traffic lights on the left; GNOME keeps the header bar with round controls on the right.
- T134 interaction: the prompt idles, an arrow cursor moves onto the window and right-clicks (a ring marks the click); PowerShell pastes on the right-click, as the console does; macOS and GNOME open a Copy, Paste, Select All menu and the cursor moves to Paste, which lights; the command appears, an Enter cue shows, the output streams, holds 5.2 s, and the loop restarts.
- T134 output: the lines now follow the real run of `irm ... | iex` and `curl ... | bash` on a fresh machine: the bootstrap's download, unverified-main warning, extract, and hand-off lines; the wordmark from `Write-NexusBanner` / `print_nexus_banner`; the tagline; the welcome line; the SKILLS & COMMANDS, AUTO-APPROVE PERMISSIONS, and INSTALL VERIFICATION banners with the ANTHROPIC header, the Claude Code checklist rows, the permissions sync line, and the runner's verify lines; the done line; and, on Windows, the farewell line and the interactive Pause prompt.
- T134 accuracy fixes against R45: the "[precheck] all required tools present" line is removed (the bootstraps print it only with NEXUS_HUB_PRECHECK_ONLY=1); the checklist marks are a check mark in brackets on PowerShell (`[char]0x2713`) and `[OK]` in bash; the verify line names the real surfaces (`commands:ok, skills:ok, CLAUDE.md SKILL_INDEX:ok`); indentation is the installers' own, kept with `white-space: pre-wrap`.
- T134 elisions: the per-platform middle (Agents, Rules, Hooks, the other platforms, the not-detected group), the remaining permission and tool sections, the interpreter check, project seeding, and the restart line (which names platforms Home does not list) show as dimmed "..." lines.
- T134 tracing: every output line carries `data-src="file:line[,line]"` naming the installer line(s) that print it, the wordmark cites its six-line range, and run-time values (repository, branch, paths, version 4.13.10, scope, the verified platform) are marked with `<var>`.
- T134 wordmark: the six lines are written once, in the PowerShell mockup, as numeric character references, so the page stays ASCII; the bash mockups hold an empty element that the script fills from it at load (both installers print the identical wordmark), which keeps the page within its byte budget.
- T134 layout: unchanged R45 order (logo and steps, command box with copy chip, mockup); the wordmark scales with the window through `font-size: min(1em, 2.05cqi)` on a container-query body, so it keeps 74 columns without wrapping or scrolling (6.4 px at 390 px); the terminal type is 12.5 px, 11 px below 560 px.

## Troubleshooting

- The first build was 500,828 bytes, over the 500,000 budget; three wordmark copies cost about 8 KB, so the source holds one and blank lines dropped their trace attribute (they print nothing), giving 494,580 bytes.
- The first capture of the PowerShell click moment showed the idle prompt: a full-page screenshot resizes the viewport, which re-fires the on-screen observer and restarts the loop; the capture script now freezes the loop through the hidden-tab path before each shot.
- The pick test found the cursor still travelling when Paste lit (a 0.9 s glide inside a 0.75 s step); the hop to Paste now takes 0.4 s.
- The first wordmark lookup matched an earlier here-string in `scripts/installer.ps1`; the build and the test now search from `Write-NexusBanner` and `print_nexus_banner`.
- The installers still declare 4.13.9; the mockup shows 4.13.10, the version this release bumps them to, marked as a run-time value.
- Tests changed in `tests/guides/test_v41310_r44_r45_home.py`: the chrome test reads the window background and asserts it is dark and neutral (luminance under 0.03, channel spread at most 6); the reduced-motion test also requires no cursor, menu, or Enter cue and a six-line wordmark; the trace test checks each line's literal text against its cited lines, the flow order, the ending per system, and the cyan title lines; a new test compares the wordmark with both installers and requires numeric references in an ASCII install section; a new per-system test records the step order (PowerShell without a menu, macOS and GNOME with one), the cursor inside the window at the click, and the cursor on the lit Paste item; the tab-switch restart is its own test.
