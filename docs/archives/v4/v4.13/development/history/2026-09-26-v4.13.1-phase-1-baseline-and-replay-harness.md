## Troubleshooting

### Credential routing

A global `ANTHROPIC_API_KEY` would take precedence over the user's Claude subscription login in their own Claude Code sessions (documented credential precedence), routing everyday use to the capped test workspace. The user stored the pilot keys under dedicated names (`NEXUS_PILOT_ANTHROPIC_API_KEY`, `NEXUS_PILOT_OPENAI_API_KEY`); the harness maps them into the child environment only.

### The spend gate

The admission required an account-side limit of no more than USD 40. The user chose USD 200 on both providers instead; that decision is recorded, and the USD 40 budget is enforced by the local ledger plus a per-turn budget flag, with the provider cap as the outer bound.
