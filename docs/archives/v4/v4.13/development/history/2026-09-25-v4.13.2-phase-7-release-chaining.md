## What this phase was for

A full run's goal ends at the end of the release. Without this phase, `/update release` would re-ask every confirmation the user already gave in the upfront round, which is exactly the mid-run stop the plan removes. This phase lets the release consume the recorded approvals one action at a time, without weakening any release check.
