# Capability usage -- v4.13.1 (for the release notes)

**Covers**: the five-part Capability usage gate entries for the two guard hooks v4.13.1 introduces. **Read by**: whoever runs `/update release` for v4.13.1 and copies these into the release notes. **Key topics**: `user-edit-guard`, `attribution-guard`, activation, validation, rollback, authority boundary.

## User-edit guard (`user-edit-guard` hook)

- **Activation**: installed and registered by default on every hook-supporting platform the installer detects; nothing to set. It stays on under `NEXUS_HOOK_PROFILE=minimal`.
- **Validation**: `grep -c user-edit-guard ~/.claude/settings.json` prints at least `1` (or the platform's own hook file, for example `~/.codex/hooks.json`).
- **Disable / rollback**: `export NEXUS_DISABLED_HOOKS=user-edit-guard` (PowerShell: `$env:NEXUS_DISABLED_HOOKS = "user-edit-guard"`); the hook then exits 0 without checking. Its records live under `~/.nexus-hub/cache/edit-guard` and can be deleted.
- **Boundary**: it guards only writes the agent makes through its own tools, blocking outside a git worktree and warning inside one; it does not watch files changed by other programs, does not back up the user's files, and sends nothing anywhere.
- **Documentation**: [`catalog/skills/workflow/user-edit-preservation/SKILL.md`](https://github.com/bendourthe/Nexus-Hub/blob/v4.13.1/catalog/skills/workflow/user-edit-preservation/SKILL.md).

## Attribution guard (`attribution-guard` hook)

- **Activation**: installed and registered by default; it stays on under `NEXUS_HOOK_PROFILE=minimal`.
- **Validation**: `nexus-hub attribution check` prints `VERIFIED` for your Git identity, and `grep -c attribution-guard ~/.claude/settings.json` prints at least `1`.
- **Disable / rollback**: `export NEXUS_DISABLED_HOOKS=attribution-guard`.
- **Boundary**: it blocks AI co-author trailers, generated-with footers, and robot badges on the publishing routes it can read (commit and tag messages, `gh pr|issue|release` bodies, `CHANGELOG.md` and `docs/` writes warn); it does not rewrite history, cannot see text sent through direct API calls, and grants no signing or identity verification.
- **Documentation**: [`catalog/style-guides/git-attribution.md`](https://github.com/bendourthe/Nexus-Hub/blob/v4.13.1/catalog/style-guides/git-attribution.md).
