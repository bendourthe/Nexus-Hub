## Changed code inputs

`python catalog/skills/documentation/technical-documentation/scripts/check_handbooks.py --root .` reported stale evidence for:

- `overview`: `scripts/lib/integrations/_catalog_adapters.py`.
- `distribution`: `scripts/installer.ps1`, `scripts/installer.sh`, `scripts/lib/integrations/_catalog_adapters.py`, `scripts/lib/integrations/cursor.py` (the last from `develop`).
