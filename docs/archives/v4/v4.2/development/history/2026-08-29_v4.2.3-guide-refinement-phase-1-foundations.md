## Subtasks

- **1.1 Fluid text** (T001): deleted the `--measure` token and all five `max-width: var(--measure)` consumers (`h1`, `p`, `.lead`, `.wip-note`). Body copy now fills `.container`, which keeps `--maxw` as the only width constraint in the file. `text-wrap: balance` stays on headings. At 1440 px, body text went from 700 px to roughly 1000 px.
- **1.2 Bare copy icon** (T002): added a `.copy-btn--bare` variant with no background, no border, and no visible label, and taught the injector to select it whenever the host is a `.cmd-cell`. The nested-chip look the maintainer flagged came from a bordered button inside a bordered chip; now only the outer chip draws a container. - **1.3 Page-nav sizing** (T003): `.pagenav a` changed from `flex: 0 1 260px` to `flex: 0 0 auto; width: auto`, so Previous / Next hug their labels instead of rendering as oversized slabs.
- **1.4 Invocation convention** (T004): added `.inv` / `.inv-cmd` / `.inv-arg` / `.inv-ph` so a slash command renders in accent, its scope in plain ink, and a placeholder dim italic. Applied to Home's verify cells; Phases 4 and 5 adopt it in Training and Cheatsheets.

## A test-harness defect found and fixed

Splitting an invocation across inner spans broke three copy-parity tests: `GuideParser` closed a `data-copy` element on the first nested closing tag among `{div, pre, code, span, button}`, so `<code data-copy="/skills list"><span>/skills</span> <span>list</span></code>` captured only `/skills`.

The page was correct; the parser was wrong. Fixed the parser to record the opening tag name and track depth, closing only on the matching end tag. This matters beyond today's markup: the truncating parser would have under-reported genuine copy-payload drift in any nested markup, so weakening the assertion instead would have quietly disarmed the guard.
