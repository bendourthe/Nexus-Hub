## Scope and evidence

Every ledger was readable. The raw status/open-section extraction is `phase4-gap-inventory.json` beside the independent rewrite backup. Format differences and resolved items nested under old Open headings make a repository-wide summed open count unreliable; this record therefore preserves each original ledger rather than fabricating a unified count. The current v4.12 ledger has strict derived counts. No prior finalized ledger was rewritten.

The rewrite preserves every historical tree; it changes commit identity and selected trailers only. Consequently it supplies no new evidence to close functional, security, native-rendering, platform-discovery or licensing gaps. Native Windows/Linux installer smoke in this phase proves the present artifact on those two hosts; it does not erase earlier failed receipts or claim macOS execution.
