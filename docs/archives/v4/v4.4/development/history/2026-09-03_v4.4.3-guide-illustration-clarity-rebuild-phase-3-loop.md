## The instruction and the trap inside it

The operator asked for bigger boxes, more visible arrows, and more readable text, and named the trap
explicitly: do not just widen the boxes without changing the font size inside them. Widening alone
would have produced six wide boxes of small type, which reads worse than the original because the
type-to-box ratio gets worse, not better.

So both halves are asserted together. Each step is `flex: 1 1 0`, which makes the share equal
regardless of label length, so `/describe` and `/implement` get the same box; and the command type
grew from 15px to 21px with the note under it from 14px to 15px. The test fails if the strip fills
the column while the type stays small, which is the specific failure the instruction warned about.

## Heads

`&rarr;` is a font glyph: its weight is whatever the typeface decided, and at 14px in the faint ink
colour it was nearly invisible. The heads are now CSS triangles, 13px by 18px, in the accent colour,
built from borders so they scale and rotate cleanly. The glyph had to be removed from the markup, not
merely hidden, or it would print beside the triangle; the test asserts each head's text is empty.

Below 820px the strip becomes a column and the same triangles rotate a quarter turn to point down,
so the sequence still reads on a phone.
