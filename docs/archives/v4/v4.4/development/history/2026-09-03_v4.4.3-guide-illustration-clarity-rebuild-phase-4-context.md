## The three complaints and what each needed

**The request and context boxes.** The label and its description shared a grid row, so `the words of the job` wrapped to three lines beside `REQUEST`. Two lines per row was the operator's instruction and is also the fix: `display: block`, the swatch riding on the label, the description beneath at the same left edge. The rule now applies to the annotated prompt scene as well, which uses the same primitive.

**The dashed noun boxes.** Four dashed boxes each containing the noun it was already labelled with. `Image` in a box told the reader nothing that `Image` had not already told them. Each kind now has a cell with its name and a drawing of the thing: a framed picture, a page with a folded corner, a folder, and a file tree. The drawings are pure geometry, so there is no text inside an SVG to escape a box, which is the same discipline Phase 2 applied to the guardrails figure. The primitive is shared, because the same dashed list appears in three scenes; the Models and Platforms rebuilds reuse it rather than each inventing one.

**The two budget boxes.** The operator said they did not read, and the percentages were why: three numbers in a legend that the reader had to map onto three unlabelled stripes. The comparison is now two meters of identical width, with the material named inside the segment that holds it and one plain sentence under each. No legend, no percentages, and the test asserts both absences so they cannot creep back.

The scene also stacks the request above the material instead of beside it. Side by side the request box got a third of the diagram column and its annotated phrases broke mid-clause; stacked, both get the full column.

## Two rule violations the broad module caught

Neither was a test being wrong.

1. **Foundations teaching copy must be project-generic.** Four coding-only terms are banned outright, and the new budget tag used one of them (`repository`). The operator asked for an agentic project-development example, which the rest of the example delivers without the banned word: rate limiting on a public API, the API source and a load-test report as material. The tag is now `Attach everything in the project`. The scene must also keep `Project folder or workspace` verbatim as one of the broad non-coding kinds, so the shortened cell name was restored.
2. **A fixed pixel `max-width` on a text-bearing element.** Phase 2 shipped `max-width: 460px` on the guardrails outer ring, and `test_no_hardcoded_text_width_caps_remain` failed here. The cause was procedural: Phase 2 ran its own module and the two it touched, not the broad one. Removed; the figure column is the only width constraint. From this phase on, the broad module runs before every commit.
