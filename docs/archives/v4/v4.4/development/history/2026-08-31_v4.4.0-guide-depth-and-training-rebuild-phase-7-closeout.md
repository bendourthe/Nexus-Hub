The correction raises Phase 2's base text floor, restores the Phase 3 hierarchy, removes excess claim tracking, and widens or recenters only the affected SVG shapes and labels. It does not compress text. Independent review caught one follow-on geometry issue before commit: the widened output node covered the old arrowhead tip.
