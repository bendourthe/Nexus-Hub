## A rename where one word changed meaning

The review renamed Goal to Query, Material to Context, and Done to Goal. The third of those is not a spelling change: `Goal` now names the finish line, which this figure has been calling `Done`. So the rename is only correct if every occurrence moves at the same time.

Five surfaces carried the old vocabulary, and all five moved: the copy paragraph above the figure, the legend terms, the legend descriptions, the flaw list (which names what is MISSING, so it has to use the same four words), and the `data-part` hooks that carry the highlight colours. Leaving the hooks alone would have produced a highlight named `goal` that marks the query, which is drift that survives for versions because nothing looks wrong on the page.

The prompt scene now shares the `context` hook with Context Engineering rather than inventing a second attribute for the same idea, and the `material` and `done` hooks are gone from the document entirely, asserted.

## The renames could not be sequential

Applying them as three string replacements in a row would have rewritten the word just written: `goal` becomes `query`, then `done` becomes `goal`, and a second pass over `goal` would catch what the first pass produced. They go through placeholders in one pass, and the script asserts no old hook survives afterwards.

## The layout, inverted for the second time

This is the third arrangement in three rounds, and each one was asked for. The first stacked the flaws under a sideways arrow pointing into empty space. v4.4.4 put them BESIDE the prompt. This round asked for the prompt on one full-width line with the flaws in a 2x2 grid below, which is neither of the previous two. The v4.4.4 beside-assertion is inverted rather than deleted, and the grid is measured as two rows of two rather than described.
