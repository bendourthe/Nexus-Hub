## Marks: what was asked, and what shipped

The operator asked for the four platforms with logos and linked an icon aggregator for each. Three
findings changed the approach, and all three are recorded in the provenance ledger rather than left
implicit:

- The aggregator serves a client-rendered page. A fetch returns application markup, and the page
  states no licence for the marks it hosts.
- This guide's ledger already approves marks for the same four vendors at pinned hashes, so reusing
  them adds no provenance surface and no outbound dependency.
- The chips label the PRODUCT while the mark is the VENDOR's. Claude Code carries the Claude mark,
  Codex the ChatGPT mark, Antigravity the Gemini mark; Cursor is exact. That is a substitution, and
  it is stated in the ledger so a reviewer can accept or reject it on the facts.

## The duplicate-id defect, caught by an existing gate

Reusing the Gemini mark made `test_ids_are_unique` fail with thirteen duplicates. This is not
cosmetic: that asset carries a mask and five blur filters referenced by `url(#...)`, so a second
copy in the same document resolves its own references against the FIRST copy's defs. The v4.4.1
ledger had namespaced those ids precisely to stop a collision with another asset, and a second
instance of the same asset collides with itself.

The chip ships the same geometry with the id prefix changed from `nxp-gm-` to `nxp-gm2-`, and the
test DERIVES the expected bytes by applying that one substitution to the approved staged asset. No
new hash is stored, which is the point: the test proves the prefix is the only difference, so a real
edit to the geometry still fails. The other three marks carry no internal ids and are byte-identical.

## Cutting the prose without cutting the argument

The scene ran about 150 words explaining what the diagram already showed. It now runs 96, on the
explicit argument that the diagram is the explanation. Three things were kept deliberately, and the
test asserts each of them, because they are the honest part rather than the descriptive part: that no
platform changes the machine unbidden, that every capability is conditional, and that the boundary is
where the condition is enforced. A word-count ceiling alone would have let a rewrite drop them.

The five stages now light in order through the shared sequencer, which is the "more animation" the
review asked for, and every stage is opacity 1 under reduced motion.
