## What the operator asked for, and what it took

The review named two numbers: triple the segment label, halve the segment title. Both are single
tokens (`--eyebrow-scale: 3`, `--title-scale: 1.2`), so the sizes are edited in one place and never
per selector. The third requirement, "no word wrapping, fit to the window size", is not something a
stylesheet can promise: a `font-size` cannot know how wide its container will be. So the rule is
measured. `NexusFit` reads what each label and title actually needs, compares it to the room the
container has, and shrinks by exactly the shortfall.

## Three defects found while building it, each a measurement error of the same family

The first two versions of the fit pass reported success and shipped overflow, which is worth
recording because the failure looked identical to a pass:

1. **A capped box hides its own overflow.** The label is an inline box with `max-width: 100%`, so
   `getBoundingClientRect()` returns the CAP, not what the glyphs need. Measuring that number proves
   only that the cap is the cap. The fix is to measure at `width: max-content` with the cap removed,
   which is the only reading that reflects the text, `::before` rule included.
2. **A grid track can be inflated by the very element being measured.** `.fx-scene.fx-stack` used
   `grid-template-columns: 1fr`, whose automatic minimum is the item's min-content contribution. A
   `nowrap` heading has no breakpoints, so the track grew to the longest line (753px inside a 672px
   scene) and dragged every sibling out of the scene box. The fit pass then read the inflated track
   as available room and concluded that everything fitted. This is the v4.4.1 `BG-11` flex
   circularity in grid form: **never measure available space against a track the measured element
   can widen.** Closed at both ends, because either alone leaves one path open: `min-width: 0` on the
   headings removes the item's contribution, and `minmax(0, 1fr)` removes the track's.
3. **`width: max-content` as a permanent style reintroduces the inflation it was added to measure.**
   It was on the label for a moment to keep the block-level label shrink-to-fit; it made the label's
   intrinsic width the track minimum. Removed; the label is a plain block.

All three were caught by tests that already existed (`test_every_scene_child_stays_inside_its_scene_box`,
`test_all_pages_meet_contrast_and_overflow_matrix`, the render-tool legibility matrix), which is the
argument for keeping containment gates that look redundant on a green day.

## The deviation, stated rather than quietly met

`D2` asked for one line at 320px too. At 320px the column is about 288px and the longest Home title
needs roughly 1,100px at the base size, so a single line costs about 8px of type. Below 720px the
fit pass holds the 15px floor and hands wrapping back; nothing ever spills. Recorded with the
arithmetic in the phase contract.

## The sweep

Fifty-five second-person occurrences across headings, prose, table headers, legends, `aria-label`
attributes, and the canvas fallback. Two judgement calls worth naming:

- The hero sentence was dictated verbatim by the operator in v4.4.2 and contained `your`. The later
  instruction is explicit and unbounded ("any text across the entire HTML"), so the newer rule wins,
  changed by exactly one word: `Upgrade any agentic AI platform ...`. Flagged for the review.
- The sweep lengthened the How-it-works section to 118 words against the v4.4.1 ceiling of 116. The
  copy was trimmed to 115 rather than the ceiling being raised.

Text the Training simulation injects at runtime is out of this version's scope; the test asserts
the static document and says so in its docstring, rather than claiming coverage it does not have.
