02 / Configuration

Know the admission boundary

Below 24 is admitted.

admitted(queue_size) compares the supplied queue size with capacity. The comparison is strict: 23 is admitted; 24 is not.

Try the boundary to see the returned result. This illustrates a function's decision; it does not add an observation to a running service.

Read the implemented service

The module loads config.json once on import. The admission function compares its input directly; it does not validate whether the value is a nonnegative integer.

import json
from pathlib import Path
CONFIG = json.loads(Path(__file__).with_name("config.json").read_text())
def attempts():
    return CONFIG["retry_limit"]
def admitted(queue_size):
    return queue_size < CONFIG["queue_capacity"]
