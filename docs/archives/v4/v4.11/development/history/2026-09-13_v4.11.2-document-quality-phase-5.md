# Session History - v4.11.2 Phase 5

**Date**: 2026-09-13
**Plan**: [v4.11.2 document and deck quality](../../plans/v4.11.2-adoption-document-and-deck-quality.md)
**Phase**: 5 - Attestation gates for the unmeasurable
**Branch**: `feat/v4.11.2-document-deck-quality`

## What this phase set out to do

Gate the rules that cannot be mechanically judged, by requiring a recorded
decision rather than a heuristic score - without drifting into scoring taste,
which the plan names as this phase's specific risk.

## Steps

1. Wrote `check_attestation.py` with completeness checks only, and put the no-scoring rule in its module docstring rather than in a commit message where nobody editing the file would see it.
2. Wrote the boundary test FIRST among the behavioural ones: a complete record with deliberately awful prose must pass.
3. Added the two countable tells to the geometric audit.
4. Ran them against the repository's own handbooks. Both failed. Narrowed both.
5. Built a pair of fixtures proving the narrowed checks still fire.
6. Wrote the rules into their three owning references.

## Troubleshooting

### Both AI tells failed real output on first write

8 callout stripes and 5 uniform card grids per handbook, against a threshold of
4. The tempting move was to raise the threshold until the handbooks passed,
which would have set the bar by what this repository happens to do rather than
by what the tell is.

Inspecting the matches instead:

- `uniform-card-grid` was matching `figure > ol`. An ordered list's items all span the container, so `spread(widths)` is zero by construction. That is not a grid; a card grid puts cards side by side. Now requires more than one column per row.
- `callout-stripe-default` was counting bordered `<figure>` elements. A frame around a figure is not a callout stripe. Now requires a text-bearing block.

Both handbooks passed after the narrowing, with the thresholds untouched.

### Proving a quieter check can still fire

Narrowing a check until real output passes is how a gate becomes decorative, so
the narrowing is paired with `ai-tells.html`, which uses each device as the
document's default, and `ai-tells-restrained.html`, which uses the same
stylesheet once each. 5 and 4 findings against 0. The pair is the evidence that
the count is the tell rather than the device.

## What went right

Putting the no-scoring rule in the module docstring and asserting it in a test.
A rule that lives only in a plan is one refactor away from being lost; a test
that fails when someone adds a quality heuristic is not.

Writing the boundary test before the behavioural ones. It framed every
subsequent check as "what must be present" rather than "what must be true of the
content", which is the distinction the whole phase rests on.

## Next

Phase 6: wiring, the global rule file, and cross-surface consistency. It makes
the composite gate callable from the commands that produce documents, which is
where every gate built so far stops being opt-in.
