# v4.14.7 Detection Signals

Summary: the per-tool evidence the installer uses to decide whether Kimi Code CLI, Qwen Code, Hermes, Pi, Aider, OpenCode, and Nexus AI Studio are installed, with the first-party source for each fact.
Read this when: changing a `"detection"` spec in `scripts/lib/integrations/<platform>.py`, adding a gated platform, or investigating a missed or false detection.
Covers: executables and collisions, home roots, tool-created entries, Nexus-Hub-written entries, vendor-only folders, application paths, and what remains unverified.

Decision ticket T001 of `docs/releases/v4/v4.14/plans/v4.14.7-installer-platform-detection.md`. All sources were fetched on 2026-10-29 from first-party vendor pages, package registries, or the vendor's own repository. The rule that consumes these values is in `docs/policy/platform-detection.md`.

## Why Seeded and Backup Files Are Not Evidence

`merge_config_hooks` (`scripts/lib/integrations/_kimi_native.py`, the `existed` branch) writes `<config>.nexus-hub.bak` whenever the config file already exists, including a `config.toml` that `seed_platform_defaults` created moments earlier in the same install. The maintainer's `~/.kimi-code` on 2026-10-29 held exactly `AGENTS.md`, `agents/`, `config.toml`, `config.toml.nexus-hub.bak`, `hooks/`, and `skills/`, with no Kimi installed. A rule that counted the backup as evidence would recreate defect A on that machine, so backups and transient files are neutral, and seeded config names are listed as Nexus-Hub entries.

## Unverified

- Kimi: the directory the install script places `kimi` in.
- Qwen: the Windows spelling of `~/.qwen`, any `QWEN_HOME` override, and the standalone installer's directory.
- Hermes: which entries exist immediately after first run; whether the installer edits PATH. Nexus-Hub writes `~/.hermes` on every OS while the Windows Hermes home is `%LOCALAPPDATA%\hermes`; that is a separate surface defect recorded as a known gap, not changed by this plan.
- Pi: whether `pi` collides with another program; what Pi auto-creates.
- Aider: the binary directory per install method.
- Nexus AI Studio: the Windows install subfolder name and the macOS and Linux locations.
- All npm-installed tools: the `.cmd` / `.ps1` shim pair in `%APPDATA%\npm` is standard npm behavior, not stated by any vendor. `safe_which` resolves the `.cmd` shim through `PATHEXT`; a `.ps1`-only install is not found, which D5 covers.
