# v4.14.8 Platform Verification

Summary: release-time first-party documentation review of the delivered platform surfaces and advisory default settings, for reviewers preparing v4.14.8. Covers all 17 integration groups of the v4.14.7 review, the 17 lever rows, and two lever findings: the Antigravity 2.0 `agentMode` value and a Nexus-AI settings surface.

## Method

Reviewed on 2026-11-04 against the [v4.14.7 platform verification](v4.14.7-platform-verification.md) as the baseline, `docs/policy/platform-read-contracts.json` and `docs/policy/platform-defaults-levers.md`. The candidate is `37c5c818b` (develop after PR #605). v4.14.8 changes no delivered surface: its only integration change is a usage-answer behavior fix in `scripts/lib/integrations/cursor.py` that writes no new path.

Every first-party source URL cited in the baseline table and the lever rows was fetched again. No page was unreachable and no URL redirected to another host. Several long pages (Claude hooks, memory and sub-agents, the Codex configuration reference, Qwen settings) were read only in their first 100,000 characters; the findings come from the parts read. No vendor application was launched or authenticated.

## Read Contracts

All 17 integration groups are unchanged from the v4.14.7 review: Claude, Codex, Antigravity 2.0, legacy Antigravity, Gemini Code Assist, Gemini CLI, Copilot, Cursor, OpenCode, Aider, Devin Desktop / Windsurf, Kimi, Qwen, OpenClaw, Nexus-AI, Hermes and Pi. Each verdict, including every DRIFT and UNVERIFIED finding, stands as recorded in the baseline. Two clarifications were observed without changing a verdict:

- Gemini CLI pages now state that Antigravity CLI replaced Gemini CLI for unpaid and Google One users on 2026-06-18, which the roster already records.
- The Antigravity workflows-to-skills migration page still describes the October 19 cutover in the future tense; the page text is otherwise unchanged.

## Default Levers

15 of 17 lever rows are unchanged. Two changed:

| Platform | Finding | Disposition |
|---|---|---|
| Antigravity 2.0 | The [CLI modes page](https://antigravity.google/docs/cli/modes/) now lists `agentMode` values `"auto"` (the default where available), `"accept-edits"`, `"plan"`, and `""` for default mode. The literal `"default"` is no longer listed. The settings path `~/.gemini/antigravity-cli/settings.json` is unchanged. Nexus-Hub seeds `{"agentMode": "default"}` when the key is absent, so the seeded value no longer matches a documented value. | Not changed in this release, because the seed is distributed behavior. Recorded as a known gap in the v4.15 ledger with the documented replacement (`""`, which keeps diff review before file changes). |
| Nexus-AI | The [repository README](https://github.com/bendourthe/Nexus-AI) now names `nexus.coding.securityPosture` (Strict, Standard or Unattended; default Standard) and `~/.nexus/settings.json`. The lever row records no documented settings surface. | Reclassification candidate only; nothing is VERIFIED from a README. Recorded as a known gap in the v4.15 ledger. |

## Result

The read contract is re-stamped for 4.14.8. The advisory lever contract keeps its gating policy: the two findings above are recorded and do not block the release.
