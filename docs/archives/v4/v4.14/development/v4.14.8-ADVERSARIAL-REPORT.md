## Considered candidates

- Quoted or backticked slang can bypass the advisory detector. This is accepted by the plan's explicit real-name/quote exemption; five actual CLI cases demonstrate the documented behavior. It is not refuted by assuming an upstream layer sanitizes it.
- Changing a tag must not change a hook decision or protocol. The seven exact continuation-format regressions and existing source-label/guardrail cases cover that observable boundary. The full local hook group remains a separate pending gate.
- A page can contain a string that looks like a Nexus-Hub approval. The policy explicitly rejects the string as authority. Correct warning behavior from every live agent is needs-live-validation; the earlier 7/10 result and MT-19/QG-10 remain open rather than being declared safe from source text alone.
- Generic edit-guard CLI errors are outside its hook branch: main dispatches hook calls to cmd_hook before the ordinary command parser/error handler. They were inspected, not relabeled as hook output merely because the same file contains both interfaces.
