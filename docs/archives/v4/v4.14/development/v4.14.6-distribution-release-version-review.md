# Distribution Handbook Release Verification - v4.14.6

**Covers**: why the distribution handbook needs no content change for the v4.14.6 release commit, and the evidence behind refreshing its installer input digests.

The v4.14.6 release commit changes only the version assignments in the two installer dependencies: `NEXUS_HUB_VERSION="4.14.5"` becomes `"4.14.6"` in `scripts/installer.sh`, and `$script:NexusHubVersion = "4.14.5"` becomes `"4.14.6"` in `scripts/installer.ps1`. `git diff -U0 origin/develop -- scripts/installer.sh scripts/installer.ps1` shows exactly those two line pairs and nothing else.

The substantive installer and CLI changes of this cycle were reviewed when they landed: the Nexus-Hub Settings extension build and the installers' agreement with recorded user choices in `docs/releases/v4/v4.14/development/v4.14.6-distribution-handbook-review.md` (PR #573), and the upgrade summary and console handoff in `docs/releases/v4/v4.14/development/upgrade-feedback-handbook-review.md` (PR #568). Both found the handbook's claims still hold.

None of the handbook's claims depends on the version value, so no handbook text or rendered output changes. Only the two installer input digests in `docs/handbooks/_sources/distribution/evidence.json` are refreshed, and this record becomes the content check's evidence. No new browser run is claimed; the existing rendered evidence still applies because the handbook output is unchanged.
