## Implementation

Stage 1's approximate line-count heuristic is replaced by deterministic directory grouping of the already resolved changed-file set. Exact paths are sorted by Unicode code point, associated once with their parent directory, and split into bundles of at most eight files. The union must equal the original set and the member count must equal its cardinality. Deleted and binary paths remain present; file existence, extensions, case, and spelling are not filters. A mismatch falls back to the known full scope ungrouped. Empty and unreadable diffs are explicitly distinguished, with unknown coverage named.

All selected personas cover every bundle against the same base. Existing consolidation still owns the merged results. The change claims improved coherence and possible reduction in redundant context reads, not fewer reviewed files or a mechanical removal of the reviewer multiplier. No second scope mechanism, grouping runtime package, or helper was added. Stages 2 onward, including finding taxonomy, modes, caps, and consolidation, are byte-identical to HEAD.
