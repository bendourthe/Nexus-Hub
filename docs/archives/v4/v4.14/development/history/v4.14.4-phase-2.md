## Implementation

Step 5 of `quality-gate-definitions/SKILL.md` now defines a recomputable gate record. A record stores the gate name, the definition's repository path and the commit SHA it ran against, and the sha256 of the definition's canonical form. Per criterion it stores the measured value (a number or a boolean only), the threshold, the comparison, the producing command with the sha256 of its output, and the outcome. The canonical form is stated once: the block from the `## Gate:` heading to the next heading of equal or higher level (or the end of the enclosing code fence or file), LF endings, trailing whitespace stripped, trailing blank lines dropped, one final LF, UTF-8 without BOM, sha256. The section also states the recompute rule, the self-attestation limit, "definition unavailable" for an unreachable SHA, the same-change-set flag, keep-every-rerun with a `stands-because` reason, the `[[egress-redaction]]` hash rule for other inputs, and one sentence handing tool-call decision records to `ai-agent-development/references/decision-policy-harness.md`.

The two former `lint-passes` examples were replaced by `gate-record` examples in the new format, and a third example (`coverage-threshold`, UNGATED with `not-measured`) was added. Each example publishes the digest of its gate block in the same file. The digests were recomputed independently with a shell pipeline (`awk`, `sed`, `sha256sum`), and the `lint-passes` value matched the test's computation exactly.

`tests/skills/test_gate_record_recompute.py` parses every `gate-record` block, recomputes each criterion outcome from measured value, comparison, and threshold, recomputes the gate outcome by the Step 3 precedence, recomputes each digest from the gate block in the same file, and asserts that a later record for the same gate states why it stands, that CRLF and LF forms hash equally, that trailing whitespace is ignored, and that a changed threshold changes the digest. A skill with fewer than three examples fails loudly instead of skipping.

The skill body is 499 lines, under the 500-line target. Room was made by removing the "What This Skill Does" list (the intro covers it), collapsing the Merge-Readiness bullets into one paragraph (the sentence restating that a usage-limit result is missing evidence was dropped because `[[verification-before-completion]]` owns it), and merging adjacent short paragraphs.
