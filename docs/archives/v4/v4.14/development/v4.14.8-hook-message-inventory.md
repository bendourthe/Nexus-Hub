**Date**: 2026-10-30. **Plan**: [plain-english-replies-and-source-labels](../plans/v4.14.8-plain-english-replies-and-source-labels.md), sub-task 3.1. **Base**: `origin/develop` at `8d055f2f1`. **Scope**: every file in `catalog/hooks/` except `_`-prefixed helpers (`_notify_common.sh`, `_notify_common.ps1`, `_skill_rules.py`, `_usage_probe.py`), which are tagged through their callers.

This inventory was taken before any hook was edited and then used to drive sub-tasks 3.2 to 3.5. The "after" column records what each message became. Line numbers refer to the files after the Phase 3 edit.

## Reading the tables

- **Channel**: `stderr`; `stdout` (plain stdout the harness injects as context or mirrors to the model); `JSON <field>` (`reason`, `permissionDecisionReason`, `systemMessage`, `additionalContext`, and the Cursor spellings `additional_context` / `followup_message`); `Write-Host` (PowerShell host stream, used by the git pre-commit review hooks).
- **Class**: `message` (tagged), `continuation` (unchanged text, printed after a tagged first line), `relay` (another program's output written verbatim; carries `nexus: hook-msg-exempt`), `machine` (exempt: ledger or state writes, `updatedInput`, rewritten commands, JSON keys).
- **Shown**: whether Claude Code / Codex show the text to the user. `yes` for stderr on exit 2 and for the approval dialog; `transcript` for stderr on exit 0 (Claude Code shows it in verbose or transcript view; Codex shows it inline); `agent` for stdout context the model reads; `unknown` where the host behavior was not verified live.
- **Values**: payload-derived text interpolated into the message, each routed through the script's escaper (`_nexus_esc` / `ConvertTo-NexusVisible` / `_nexus_esc`).
