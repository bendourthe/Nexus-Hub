# Distribution Handbook Release Verification - v4.14.1

**Covers**: why the distribution handbook needs no content change for the v4.14.1 release, and the evidence behind refreshing its installer input digests.

The v4.14.1 release changes only the version assignments in the two installer dependencies: `NEXUS_HUB_VERSION="4.14.0"` becomes `"4.14.1"` in `scripts/installer.sh`, and `$script:NexusHubVersion = "4.14.0"` becomes `"4.14.1"` in `scripts/installer.ps1`. `git diff -U0 origin/develop -- scripts/installer.sh scripts/installer.ps1` shows exactly those two line pairs and nothing else.

The handbook explains distribution, settings ownership, attributed identity, and verification boundaries. None of those claims depends on the version value, so no handbook text or rendered output changes. Every other mapped dependency is unchanged from develop. Only the two installer input digests in `docs/handbooks/_sources/distribution/evidence.json` are refreshed, and this record becomes the content check's evidence. No new browser run is claimed; the existing rendered evidence still applies because the handbook output is unchanged.
