## 2. Chronological Steps

### 2.1 Author the canonical style guide

**Plan specification**: Sub-task 1.1. Create `catalog/style-guides/agent-communication.md` covering seven sections, every rule written as a testable behavior, 150 to 250 lines, ending with a binary Verification checklist.

**What was done**: Created the guide at 137 lines with all seven sections (response structure, plain language, placeholder discipline, guided-steps protocol, end-of-task report shape, docs deep-link rule, waiting-state interim updates), an 11-item Verification checklist, and a Related guidance section. The opening paragraph states the boundary against `markdown.md` and cross-links it, as required.

Worked examples included: a three-way placeholder before/after (underivable, derivable-and-filled, unknowable-and-flagged), an error-recovery example showing the full renumbered remaining sequence, and a bad/good waiting-state pair modeled on a technical dump that buries the "tests running" signal.

**Deviation**: the file came in at 137 lines rather than the 150 to 250 target. The seven sections and the checklist are complete; the shortfall is compression, not omission, and padding to hit a line count would contradict the guide's own rules.

### 2.2 Decision record

**Plan specification**: Sub-task 1.2. Record the policy decision with mandatory alternatives.

**What was done**: Created `docs/decisions/implemented/policy/2026-08-18-agent-communication-contract.md` with `## Problem`, `## Decision`, `## Alternatives considered` (five alternatives: inline into every template, hook-based enforcement, widen `markdown.md`, skill-only with no template section, do nothing), and `## Consequences` (five, including the parity-gate coverage gap and the budget consumption).

**Deviation**: the plan specified `docs/decisions/accepted/policy/`. No `accepted` lifecycle exists. Per `docs/decisions/README.md` the three lifecycles are `proposed`, `implemented`, and `rejected`, and a shipped decision belongs in `implemented`. Filed there; the filename date (2026-08-18) is preserved as the decision date per the README rule.

## 3. Troubleshooting

**`make` is not installed on this machine.** The Makefile targets could not be invoked directly. Resolved by generating a shell script from the Makefile recipe lines (a scratchpad helper parses the target and emits its commands) and running that through Git Bash. This is a local environment workaround, not a repo change; nothing was committed for it.

**Heredoc truncation.** The first attempt to write the style guide through a shell heredoc failed with an unterminated-heredoc parse error, caused by command-length truncation rather than by the content. Switched to direct file writes for the large artifacts.
